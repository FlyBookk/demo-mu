### 2.1 汇总计算测试用例

#### TC-SUM-001 收入总额计算-基础场景

| 项目 | 内容 |
|------|------|
| **用例编号** | TC-SUM-001 |
| **功能模块** | 汇总报表 - 收入计算 |
| **用例标题** | 验证基于配送数据的收入总额计算正确性 |
| **优先级** | P0 |
| **前置条件** | 1. 系统已初始化站点配置(US站)<br>2. 已导入配送数据(含商品价格、运费等)<br>3. 已导入对应日期的汇率数据 |
| **测试步骤** | 1. 准备配送测试数据：<br>&nbsp;&nbsp;- 订单1: 商品价格$100, 商品税$8, 运费$5, 运费税$0.4, 配送日期2025-07-15<br>&nbsp;&nbsp;- 订单2: 商品价格$200, 商品税$16, 运费$8, 运费税$0.64, 配送日期2025-07-16<br>2. 准备汇率数据：<br>&nbsp;&nbsp;- 2025-07-15 USD汇率: 7.2000<br>&nbsp;&nbsp;- 2025-07-16 USD汇率: 7.2100<br>3. 进入汇总报表页面<br>4. 选择2025年Q3季度、US站点<br>5. 点击"生成报表" |
| **预期结果** | 收入总额计算正确：<br>订单1收入 = (100+8+5+0.4) × 7.2000 = 816.48 CNY<br>订单2收入 = (200+16+8+0.64) × 7.2100 = 1619.66 CNY<br>总收入 = 816.48 + 1619.66 = **2436.14 CNY** |
