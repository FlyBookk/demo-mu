## 1. 接口概述

本文档定义销售数据双格式导入功能的所有后端API接口，支持亚马逊原始数据和ERP结算数据两种格式的导入。

### 1.1 接口清单

| 序号 | 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|------|
| 1 | 上传文件 | POST | /v1/business/sales/upload | 上传文件并解析表头 |
| 2 | 预览数据 | POST | /v1/business/sales/preview | 预览解析后的数据 |
| 3 | 执行导入 | POST | /v1/business/sales/import/execute | 执行销售数据导入 |
| 4 | 获取导入进度 | GET | /v1/business/sales/import/progress/{batchNo} | 获取导入进度 |
| 5 | 获取模板列表 | GET | /v1/config/field-mapping-templates/by-type | 按类型获取模板 |
| 6 | 获取目标字段 | GET | /v1/config/target-fields | 获取目标字段元数据 |

### 1.2 通用响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": 1705660800000,
  "requestId": "uuid"
}
```

### 1.3 错误码定义

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 10001 | 参数校验失败 |
| 10002 | 文件格式不支持 |
| 10003 | 文件解析失败 |
| 10004 | 模板不存在 |
| 10005 | 字段映射不完整 |
| 10006 | 数据格式错误 |
| 10007 | 重复数据 |

## 2. 接口详细定义

### 2.1 上传文件

**接口路径**: `POST /v1/business/sales/upload`

**接口说明**: 上传销售数据文件，解析表头并返回源字段列表，用于后续的字段映射。

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | MultipartFile | 是 | CSV文件 |
| sourceType | String | 是 | 数据源类型：ORIGINAL-亚马逊原始数据, ERP-ERP结算数据 |
| siteCode | String | 否 | 站点编码（仅ERP数据需要预选，ORIGINAL自动识别） |

**请求示例**:

```bash
curl -X POST 'http://localhost:8080/api/v1/business/sales/upload' \
  -H 'Authorization: Bearer {token}' \
  -F 'file=@sales_data.csv' \
  -F 'sourceType=ORIGINAL'
```

**响应参数**:

| 字段 | 类型 | 说明 |
|------|------|------|
| fileId | String | 文件唯一标识（用于后续预览和导入） |
| fileName | String | 原始文件名 |
| fileSize | Long | 文件大小(bytes) |
| filePath | String | 服务器存储路径 |
| totalRows | Integer | 总行数（不含表头） |
| headerRow | Integer | 表头所在行号（从1开始） |
| sourceFields | List\<String\> | 解析出的源字段列表 |
| detectedSiteCode | String | 自动识别的站点编码（仅ORIGINAL有效） |
| detectedSiteCodes | List\<String\> | 文件中包含的所有站点（多站点文件） |
| encoding | String | 文件编码 |
| sampleData | List\<Map\> | 前5行样例数据 |

**响应示例**:

```json
{
  "code": 0,
  "message": "success",
  "data": {
```

### 2.2 预览数据

**接口路径**: `POST /v1/business/sales/preview`

**接口说明**: 根据选择的模板和映射配置，预览解析后的数据（前10行），用于用户确认。

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fileId | String | 是 | 上传返回的文件ID |
| sourceType | String | 是 | 数据源类型：ORIGINAL/ERP |
| siteCode | String | 是 | 站点编码 |
| templateId | Long | 是 | 字段映射模板ID |
| quarter | String | 否 | 数据所属季度（YYYY-QN格式） |

**请求示例**:

```json
{
  "fileId": "f8c3d2a1-5e4b-4c3a-9d8f-1a2b3c4d5e6f",
  "sourceType": "ORIGINAL",
  "siteCode": "US",
  "templateId": 1,
  "quarter": "2025-Q3"
}
```

**响应参数**:

| 字段 | 类型 | 说明 |
|------|------|------|
| totalRows | Integer | 总数据行数 |
| previewRows | Integer | 预览行数（最多10行） |
| columns | List\<ColumnMeta\> | 列元数据 |
| data | List\<Map\> | 预览数据 |
| mappingStatus | MappingStatus | 映射状态统计 |
| warnings | List\<String\> | 警告信息列表 |

**ColumnMeta 结构**:

| 字段 | 类型 | 说明 |
|------|------|------|
| field | String | 字段名 |
| label | String | 显示名称 |
| type | String | 字段类型 |
| sourceField | String | 对应的源字段 |

**MappingStatus 结构**:

| 字段 | 类型 | 说明 |
|------|------|------|
| totalFields | Integer | 总目标字段数 |
| mappedFields | Integer | 已映射字段数 |
| requiredMissing | List\<String\> | 缺失的必填字段 |

**响应示例**:

### 2.3 执行导入

**接口路径**: `POST /v1/business/sales/import/execute`

**接口说明**: 执行销售数据导入，支持异步处理大文件。

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fileId | String | 是 | 上传返回的文件ID |
| sourceType | String | 是 | 数据源类型：ORIGINAL/ERP |
| siteCode | String | 是 | 站点编码 |
| templateId | Long | 是 | 字段映射模板ID |
| quarter | String | 否 | 数据所属季度 |
| skipDuplicate | Boolean | 否 | 是否跳过重复数据（默认true） |
| overwriteDuplicate | Boolean | 否 | 是否覆盖重复数据（默认false） |

**请求示例**:

```json
{
  "fileId": "f8c3d2a1-5e4b-4c3a-9d8f-1a2b3c4d5e6f",
  "sourceType": "ORIGINAL",
  "siteCode": "US",
  "templateId": 1,
  "quarter": "2025-Q3",
  "skipDuplicate": true,
  "overwriteDuplicate": false
}
```

**响应参数**:

| 字段 | 类型 | 说明 |
|------|------|------|
| batchNo | String | 导入批次号 |
| status | String | 导入状态：PENDING/PROCESSING/SUCCESS/PARTIAL/FAIL |
| totalCount | Integer | 总记录数 |
| successCount | Integer | 成功数 |
| failCount | Integer | 失败数 |
| skipCount | Integer | 跳过数（重复） |
| importRecordId | Long | 导入记录ID |
| async | Boolean | 是否异步处理 |
| estimatedSeconds | Integer | 预估耗时（秒） |

**响应示例**:

```json
{
  "code": 0,
  "message": "导入任务已提交，正在处理中...",
  "data": {
    "batchNo": "IMP20260121143052001",
    "status": "PROCESSING",
    "totalCount": 5000,
    "successCount": 0,
    "failCount": 0,
    "skipCount": 0,
    "importRecordId": 123,
    "async": true,
    "estimatedSeconds": 30
  }
}
```

### 2.4 获取导入进度

**接口路径**: `GET /v1/business/sales/import/progress/{batchNo}`

**接口说明**: 获取导入任务的实时进度（轮询方式）。

**路径参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| batchNo | String | 是 | 导入批次号 |

**响应参数**:

| 字段 | 类型 | 说明 |
|------|------|------|
| batchNo | String | 批次号 |
| status | String | 状态：PENDING/PROCESSING/SUCCESS/PARTIAL/FAIL |
| totalCount | Integer | 总记录数 |
| processedCount | Integer | 已处理数 |
| successCount | Integer | 成功数 |
| failCount | Integer | 失败数 |
| skipCount | Integer | 跳过数 |
| percentage | Integer | 进度百分比(0-100) |
| message | String | 当前处理信息 |
| errorDetails | List\<ErrorDetail\> | 错误详情（最多50条） |
| startTime | String | 开始时间 |
| endTime | String | 结束时间（完成后有值） |

**ErrorDetail 结构**:

| 字段 | 类型 | 说明 |
|------|------|------|
| row | Integer | 行号 |
| orderId | String | 订单ID |
| error | String | 错误信息 |

**响应示例**:


## 5. 前端对接说明

### 5.1 导入流程

```
1. 选择站点 → 2. 选择数据源类型 → 3. 选择模板 → 4. 上传文件 → 5. 预览确认 → 6. 执行导入
```

### 5.2 调用顺序

1. **步骤1-3**: 调用 `GET /v1/config/field-mapping-templates/by-type` 获取模板列表
2. **步骤4**: 调用 `POST /v1/business/sales/upload` 上传文件
3. **步骤5**: 调用 `POST /v1/business/sales/preview` 预览数据
4. **步骤6**: 调用 `POST /v1/business/sales/import/execute` 执行导入
5. **轮询**: 调用 `GET /v1/business/sales/import/progress/{batchNo}` 获取进度
