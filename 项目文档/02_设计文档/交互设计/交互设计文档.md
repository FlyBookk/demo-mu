## 1. 设计概述

### 1.1 设计目标

| 目标 | 说明 |
|------|------|
| 效率优先 | 针对财务人员日常操作，最小化操作步骤，提高工作效率 |
| 学习成本低 | 遵循通用B端设计规范，降低用户学习成本 |
| 容错友好 | 重要操作有确认提示，错误有明确指引，支持数据回滚 |
| 信息清晰 | 数据展示层次分明，重要信息突出，状态一目了然 |

### 1.2 设计原则

```
┌─────────────────────────────────────────────────────────────────────┐
│                          设计原则                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  [效率] 减少点击次数，支持快捷操作，常用功能一步到达                   │
│                                                                     │
│  [清晰] 信息层次分明，视觉引导明确，状态反馈及时                       │
│                                                                     │
│  [一致] 交互模式统一，视觉风格一致，组件复用规范                       │
│                                                                     │
│  [容错] 危险操作二次确认，支持撤销回滚，错误提示友好                   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.3 目标用户

| 用户角色 | 使用场景 | 操作频率 | 核心诉求 |
|---------|---------|---------|---------|
| 管理员 | 系统配置、用户管理 | 低频 | 快速配置、权限管控 |
| 财务人员 | 数据导入、报表生成 | 高频 | 操作高效、数据准确 |
| 查看者 | 数据查看、报表导出 | 中频 | 快速查找、便捷导出 |

#### 3.4.3 映射操作交互

**方式一：拖拽连线**
```
操作流程:
1. 鼠标按住左侧CSV字段卡片
2. 拖拽到右侧目标系统字段
3. 释放鼠标，建立映射关系
4. 显示连接线动画

视觉反馈:
- 拖拽中: 卡片半透明跟随鼠标
- 有效目标: 右侧字段高亮显示可接受区域
- 无效目标: 显示禁止图标
- 映射成功: 绿色连线动画
```

**方式二：点击选择**
```
操作流程:
1. 点击左侧CSV字段，字段高亮选中
2. 点击右侧目标系统字段
3. 自动建立映射关系

视觉反馈:
- 选中状态: 蓝色边框 + 选中图标

```

快捷操作:

| 中屏 | 1200px - 1919px | 正常展示，侧边栏可收起 |
| 小屏 | < 1200px | 提示用户使用更大屏幕 |

### 7.2 适配策略

```
大屏 (>= 1920px):
- 侧边栏: 200px 展开
- 内容区: 自适应
- 表格: 完整展示所有列

中屏 (1200px - 1919px):
- 侧边栏: 可收起为 60px
- 内容区: 自适应
- 表格: 固定关键列，其他列横向滚动

小屏 (< 1200px):
- 显示提示: "为获得最佳体验，请使用 1200px 以上分辨率的设备"
```
