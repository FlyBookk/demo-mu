## 一、项目概述

### 1.1 项目名称

**慕声亚马逊转口贸易报税管理系统** (Musheng Amazon Transit Trade Tax Management System)

### 1.2 项目定位

面向跨境电商企业的税务管理解决方案，专注于亚马逊多站点转口贸易业务的销售数据管理、汇率换算和季度报税汇总。

### 1.3 核心价值

| 价值点 | 说明 |
|--------|------|
| **数据整合** | 统一管理US/CA/UK/DE四个站点的销售、配送、广告数据 |
| **自动计算** | 自动汇率换算（支持节假日顺延）、退款归属、VAT计算 |
| **灵活配置** | 可配置的字段映射、交易类型映射，适应不同站点数据格式 |
| **合规报税** | 生成符合税务要求的季度汇总报表 |

### 1.4 目标用户

| 用户角色 | 职责 | 使用频率 |
|----------|------|----------|
| 管理员 | 系统配置、用户管理 | 低频 |
| 财务人员 | 数据导入、报表生成 | 高频（日常） |
| 查看者 | 数据查看、报表导出 | 中频 |

### 4.2 核心功能详解

#### 4.2.1 数据导入与字段映射

```
CSV文件上传 → 表头解析 → 站点识别 → 加载映射模板 → 字段映射画布 → 数据预览 → 确认导入
     │              │           │            │              │           │
     ▼              ▼           ▼            ▼              ▼           ▼
  分片上传      多语言支持   自动识别    可视化拖拽     实时预览    异步导入
  (>10MB)      (EN/DE)    (US/CA/UK/DE)  连线映射     前10行      进度显示
```

**支持的数据类型**:
- 销售数据 (Sales Data) - 亚马逊Settlement Report
- 配送数据 (Shipping Data) - 配送明细
- 广告数据 (Advertising Data) - 广告费发票
- 汇率数据 (Exchange Rate) - 每日汇率

#### 4.2.2 汇率换算与节假日顺延

```
查询汇率(日期)
    │
    ▼
┌─────────────┐
│ 是否周末?   │──是──▶ 顺延到下一天
└─────────────┘
    │否
    ▼
┌─────────────┐
│ 是否节假日? │──是──▶ 顺延到下一天
└─────────────┘
    │否
    ▼
返回当日汇率
```

#### 4.2.3 汇总计算逻辑

```
汇总报表计算公式:

收入总额(a) = Σ(配送日期在季度内的订单金额 × 配送日期汇率)
退款金额(b) = Σ(原订单配送日期在季度内的退款金额 × 配送日期汇率)
净收入(c)   = 收入总额 - 退款金额
配送成本    = Σ(配送成本 × 配送日期汇率)
广告费用    = Σ(广告费 × 录入日期汇率)
VAT税额     = 净收入 × VAT税率 (UK:20%, DE:19%)
```

## 七、安全设计

### 7.1 认证授权

| 安全措施 | 实现方式 |
|----------|----------|
| 用户认证 | Sa-Token + JWT |
| 会话管理 | Redis存储，30分钟超时 |
| 密码安全 | BCrypt加密存储 |
| 权限控制 | RBAC模型，注解鉴权 |

| 安全措施 | 实现方式 |
|----------|----------|
| 数据隔离 | 按站点隔离，租户模式 |

| XSS防护 | 前端输入过滤，后端转义 |
| 敏感信息 | 配置文件加密，日志脱敏 |
| 操作审计 | 完整操作日志记录 |

| 安全措施 | 实现方式 |

| HTTPS | Nginx SSL终端 |
