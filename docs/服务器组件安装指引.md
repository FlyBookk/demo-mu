# 慕声报税系统 — 服务器组件安装指引

> 本文档供阿里云 ECS Agent 直接读取并执行。
> 执行前提：全新 Linux 服务器，已有 root 权限，可访问公网。
> 支持系统：**CentOS 7/8/9、AlmaLinux 8/9、Ubuntu 20.04/22.04/24.04**
> 应用运行用户：`musheng`（密码：`musheng`）

---

## 第一步：检测操作系统

```bash
cat /etc/os-release | grep -E "^ID=|^VERSION_ID="
```

---

## 第二步：创建系统用户 musheng

> 所有应用文件均部署在此用户下，服务也以此用户身份运行。

```bash
# 创建用户（含家目录）
useradd -m -s /bin/bash musheng

# 设置密码
echo "musheng:musheng" | chpasswd

# 允许 musheng 用户通过 sudo 管理自身服务（无需 root 密码）
# 仅授权必要命令，不给完整 root 权限
cat > /etc/sudoers.d/musheng << 'EOF'
musheng ALL=(ALL) NOPASSWD: \
    /usr/bin/systemctl start musheng, \
    /usr/bin/systemctl stop musheng, \
    /usr/bin/systemctl restart musheng, \
    /usr/bin/systemctl status musheng, \
    /usr/bin/systemctl reload nginx, \
    /usr/bin/systemctl restart nginx, \
    /usr/bin/journalctl -u musheng *
EOF
chmod 440 /etc/sudoers.d/musheng

# 验证用户创建
id musheng
# 期望：uid=xxxx(musheng) gid=xxxx(musheng) groups=xxxx(musheng)
```

## 第四步：安装 MySQL 8

### CentOS / AlmaLinux / Rocky Linux

```bash
yum install -y mysql-server
systemctl start mysqld
systemctl enable mysqld
systemctl status mysqld --no-pager
```

### Ubuntu / Debian

```bash
apt-get install -y mysql-server
systemctl start mysql
systemctl enable mysql
systemctl status mysql --no-pager
```

### 初始化 MySQL（创建业务库和账号）

> CentOS 首次安装会生成临时密码，先取出：

```bash
# CentOS：查看临时密码
grep "temporary password" /var/log/mysqld.log | awk '{print $NF}'

# Ubuntu：首次免密登录
sudo mysql
```

进入 MySQL 后执行（将 `YourDbPassword` 替换为实际数据库密码）：

```sql
-- CentOS 首次必须先修改 root 密码（含大小写+数字+符号）
ALTER USER 'root'@'localhost' IDENTIFIED BY 'RootStr0ngPass!';

-- 创建业务数据库
CREATE DATABASE IF NOT EXISTS musheng_tax
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建数据库业务账号（与应用连接使用）
CREATE USER IF NOT EXISTS 'musheng'@'localhost' IDENTIFIED BY 'YourDbPassword';
GRANT ALL PRIVILEGES ON musheng_tax.* TO 'musheng'@'localhost';
FLUSH PRIVILEGES;

EXIT;
```

**验证**：

```bash
mysql -u musheng -pYourDbPassword -e "SHOW DATABASES;" 2>/dev/null | grep musheng_tax
```

## 第七步：配置 Nginx

创建 `/etc/nginx/conf.d/musheng.conf`：

```bash
cat > /etc/nginx/conf.d/musheng.conf << 'EOF'
server {
    listen 80;
    server_name _;

    root /opt/musheng/frontend;
    index index.html;

    # 前端 SPA（History 路由模式）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 反向代理后端 API
    location /api/ {
        proxy_pass         http://127.0.0.1:8080/api/;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_send_timeout    300s;
        proxy_read_timeout    300s;
    }

    client_max_body_size 100M;
}
EOF
```

禁用 Nginx 默认配置并验证：

```bash
# CentOS：注释掉默认 server 块
sed -i 's/^    server {/    #server {/' /etc/nginx/nginx.conf 2>/dev/null || true

# Ubuntu：禁用默认站点
rm -f /etc/nginx/sites-enabled/default 2>/dev/null || true

# 检查配置语法
nginx -t

# 重载
systemctl reload nginx
```

## 第八步：配置 systemd 服务

以 **root** 身份创建服务文件（服务本身以 `musheng` 用户运行）：

```bash
cat > /etc/systemd/system/musheng.service << 'EOF'
[Unit]
Description=Musheng Tax System
After=network.target mysqld.service mysql.service

[Service]
Type=simple
User=musheng
Group=musheng
WorkingDirectory=/opt/musheng/backend
ExecStart=/usr/bin/java -jar /opt/musheng/backend/musheng-web-1.0.0-SNAPSHOT.jar \
          --spring.profiles.active=prod
Restart=on-failure
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable musheng
```

> 此时不启动服务，等上传 JAR 和配置文件后再启动。

## 第九步：配置生产环境参数

以 **musheng 用户**身份创建配置文件（将 `YourDbPassword` 替换为实际密码）：

```bash
su - musheng -c "cat > /opt/musheng/backend/application-prod.yml << 'EOF'
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/musheng_tax?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: musheng
    password: YourDbPassword

app:
  upload:
    chunk-dir: /opt/musheng/uploads/chunks
    final-dir:  /opt/musheng/uploads/files
    temp-dir:  /opt/musheng/uploads/temp

logging:
  level:
    root: warn
    com.musheng: info
EOF"
```

## 第十步：开放防火墙

### CentOS（firewalld）

```bash
systemctl is-active firewalld && {
  firewall-cmd --permanent --add-service=http
  firewall-cmd --permanent --add-service=ssh
  firewall-cmd --reload
  firewall-cmd --list-all
}
```

### Ubuntu（ufw）

```bash
ufw allow 22/tcp
ufw allow 80/tcp
echo "y" | ufw --force enable
ufw status
```

### 阿里云安全组

> 还需在**阿里云控制台 → ECS → 安全组 → 入方向**添加规则：
>
> | 协议 | 端口范围 | 授权对象 |
> |------|----------|----------|
> | TCP | 80 | 0.0.0.0/0 |
> | TCP | 22 | 你的 IP（或 0.0.0.0/0） |

## 第十一步：导入数据库（首次部署）

将 `musheng_tax.sql` 上传到服务器后，以 musheng 用户执行：

```bash
# root 上传 SQL 文件后，修改所属
chown musheng:musheng /opt/musheng/musheng_tax.sql

# 导入
su - musheng -c "mysql -u musheng -pYourDbPassword musheng_tax < /opt/musheng/musheng_tax.sql"
echo "数据库导入完成，退出码：$?"
```

---

## 第十二步：上传应用文件并启动

### 从本地开发机上传（使用 musheng 用户）

```bash
# 上传 JAR
scp musheng-web-1.0.0-SNAPSHOT.jar musheng@<服务器IP>:/opt/musheng/backend/

# 上传前端静态文件
scp -r dist/* musheng@<服务器IP>:/opt/musheng/frontend/

# 上传管理脚本
scp scripts/musheng-manage.sh musheng@<服务器IP>:/opt/musheng/
```

### 在服务器上启动服务（root 执行）

```bash
systemctl start musheng
sleep 5
systemctl status musheng --no-pager
```

## 全量验证检查单

安装完成后逐项执行，确认输出正常：

```bash
# 1. Linux 用户
id musheng
# 期望：uid=xxxx(musheng) ...

# 2. Java 版本
java -version 2>&1 | head -1
# 期望：openjdk version "17...

# 3. MySQL 状态
systemctl is-active mysqld 2>/dev/null || systemctl is-active mysql
# 期望：active

# 4. Nginx 状态
systemctl is-active nginx
# 期望：active

# 5. 后端服务状态
systemctl is-active musheng
# 期望：active

# 6. 服务运行用户确认
ps aux | grep musheng-web | grep -v grep | awk '{print $1}'
# 期望：musheng

# 7. 端口监听
ss -tlnp | grep -E ':80|:8080'
# 期望：两个端口均有监听

# 8. 目录权限

# 期望：所有目录 owner 均为 musheng

# 9. 前端访问
curl -s -o /dev/null -w "HTTP %{http_code}\n" http://localhost/
# 期望：HTTP 200

# 10. API 访问

```
