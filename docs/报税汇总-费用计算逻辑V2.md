## 一、费用分类总览

| 序号 | 费用分类 | 说明 |
|------|----------|------|
| 1 | **收入总额** | 发货订单的销售收入 |
| 2 | **退款总额** | 退款订单的金额（按发货归属 + 按结算时间两个维度） |
| 3 | **消费税** | 平台代扣税 |
| 4 | **佣金/服务费** | 销售费用 + FBA费用 + 其他交易费 + 其他 |
| 5 | **其他费** | 非收入/退款类型的所有费用 |

---

## 二、核心计算规则

### 2.1 交易类型分类

| 交易分类 | transaction_category | 对应来源(type) |
|---------|---------------------|---------------|
| 收入 | income | Shipment, Retrocharge |
| 退款 | refund | Refund |
| 其他 | fee, adjustment, other | ServiceFee, Adjustment, Liquidations 等 |

---

### 2.2 收入/退款类型的计算逻辑

**适用范围**：`transaction_category = 'income'` 或 `transaction_category = 'refund'`

#### 数据获取流程

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 按查询时间范围筛选【配送数据】（发货时间在查询范围内）           │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  2. 获取配送数据的订单号列表                                       │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  3. 根据订单号查询【销售数据】（需要扩展结算时间范围，建议+2个月）    │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  4. 按配送数据的汇率进行金额换算                                   │
└─────────────────────────────────────────────────────────────────┘
```

#### 计算公式

**收入总额** = 产品销售 + 产品税 + 运费收入 + 运费税 + 礼品包装费 + 礼品包装税 + 监管费 + 监管费税 + 促销折扣 + 促销折扣税

**退款总额** = 产品销售 + 产品税 + 运费收入 + 运费税 + 礼品包装费 + 礼品包装税 + 监管费 + 监管费税 + 促销折扣 + 促销折扣税

**消费税** = 平台代扣税 (marketplace_withheld_tax)

**佣金/服务费** = 销售费用 (selling_fees) + FBA费用 (fba_fees) + 其他交易费 (other_transaction_fees) + 其他 (other)

#### 字段映射

| 费用项 | 数据库字段 | 来源说明 |
|--------|-----------|---------|
| 产品销售 | product_sales | Principal |
| 产品税 | product_sales_tax | Tax, TaxAmount 等 |
| 运费收入 | shipping_credits | ShippingCharge, ShippingDiscount 等 |
| 运费税 | shipping_credits_tax | ShippingTax, ShippingDiscountTax |
| 礼品包装费 | gift_wrap_credits | GiftWrap, GiftwrapChargeback |
| 礼品包装税 | gift_wrap_credits_tax | GiftWrapTax |
| 监管费 | regulatory_fee | RegulatoryFee |
| 监管费税 | regulatory_fee_tax | TaxOnRegulatoryFee |
| 促销折扣 | promotional_rebates | PromotionDiscount |
| 促销折扣税 | promotional_rebates_tax | PromotionDiscountTax |
| 平台代扣税 | marketplace_withheld_tax | MarketplaceFacilitatorVAT/Tax 系列 |
| 销售费用 | selling_fees | Commission, RefundCommission |
| FBA费用 | fba_fees | FBAPerUnitFulfillmentFee 等 |
| 其他交易费 | other_transaction_fees | DigitalServicesFee 等 |
| 其他 | other | Revenue, FeeAmount 等 |

### 2.3 其他类型（非收入/退款）的计算逻辑

**适用范围**：`transaction_category` 不是 `income` 也不是 `refund`

#### 情况一：有订单号

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 按查询时间范围筛选【配送数据】（发货时间在查询范围内）           │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  2. 根据配送数据订单号匹配【销售数据】中的其他费用                  │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  3. 按配送数据的汇率进行金额换算                                   │
└─────────────────────────────────────────────────────────────────┘
```

#### 情况二：无订单号

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 直接按结算时间（transaction_date）查询【销售数据】             │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  2. 按销售数据自带的汇率进行金额换算                               │
└─────────────────────────────────────────────────────────────────┘
```

#### 计算公式

**其他费** = 所有非收入/退款类型数据的 `total` 字段汇总

---

### 2.4 退款的双维度统计

| 维度 | 数据获取方式 | 汇率来源 | 用途 |
|------|-------------|---------|------|
| **按发货归属** | 配送数据订单号 → 销售数据 | 配送数据汇率 | 主要报税维度 |
| **按结算时间** | 直接按 transaction_date 查询 | 销售数据汇率 | 辅助参考维度 |

---

## 三、汇率使用规则

| 场景 | 汇率来源 | 说明 |
|------|---------|------|
| 收入计算 | 配送数据的发货日期汇率 | 从配送表获取 |
| 退款-按发货归属 | 原订单的配送日期汇率 | 从配送表获取 |
| 退款-按结算时间 | 结算日期汇率 | 从销售数据获取 |
| 其他费用-有订单号 | 原订单的配送日期汇率 | 从配送表获取 |
| 其他费用-无订单号 | 结算日期汇率 | 从销售数据获取 |

## 五、与现有逻辑的对比

| 项目 | 现有逻辑 (V1) | 新逻辑 (V2) | 变化点 |
|------|-------------|-------------|--------|
| 收入计算 | 配送数据的 revenueTotal 或手动计算 | 配送→销售关联，按配送汇率 | 增加销售数据关联 |
| 退款计算 | 双维度（按发货/按结算） | 双维度保留 | 公式调整，与收入一致 |
| 消费税 | 无独立字段 | **新增**：marketplace_withheld_tax | 新增费用项 |
| 佣金/服务费 | totalServiceFee | 拆分为4个子项汇总 | 细化计算 |
| 其他费 | feeBreakdown | 按订单号归属优先 | 汇率规则变化 |
| 净收入 | 计算并展示 | **移除** | 不再计算 |
| 广告费 | 独立计算 | 保持不变 | 无变化 |

## 六、数据模型调整建议

### 6.1 TaxReportSummary DTO 调整

```java
public class TaxReportSummary {
    // === 基础信息 ===
    String siteCode;
    String siteName;
    String yearQuarter;
    String currencyCode;

    // === 收入 ===
    BigDecimal totalRevenue;         // 收入总额（原币）
    BigDecimal totalRevenueCny;      // 收入总额（人民币）
    Integer shippingOrderCount;      // 发货订单数

    // === 退款（按发货归属）===
    BigDecimal refundByShipment;     // 退款总额-按发货归属（原币）
    BigDecimal refundByShipmentCny;  // 退款总额-按发货归属（人民币）
    Integer refundCountByShipment;   // 退款笔数-按发货归属

    // === 退款（按结算时间）===
    BigDecimal refundBySettlement;     // 退款总额-按结算时间（原币）
    BigDecimal refundBySettlementCny;  // 退款总额-按结算时间（人民币）
    Integer refundCountBySettlement;   // 退款笔数-按结算时间

    // === 消费税 ===
    BigDecimal consumptionTax;       // 消费税/平台代扣税（原币）
    BigDecimal consumptionTaxCny;    // 消费税/平台代扣税（人民币）

    // === 佣金/服务费（拆分）===
    BigDecimal sellingFees;          // 销售费用（原币）
    BigDecimal sellingFeesCny;       // 销售费用（人民币）
    BigDecimal fbaFees;              // FBA费用（原币）
    BigDecimal fbaFeesCny;           // FBA费用（人民币）
    BigDecimal otherTransactionFees; // 其他交易费（原币）
    BigDecimal otherTransactionFeesCny; // 其他交易费（人民币）
    BigDecimal otherFees;            // 其他（原币）
    BigDecimal otherFeesCny;         // 其他（人民币）
    BigDecimal totalServiceFee;      // 佣金/服务费合计（原币）
    BigDecimal totalServiceFeeCny;   // 佣金/服务费合计（人民币）

    // === 其他费 ===
    BigDecimal miscFees;             // 其他费（原币）- 非收入/退款类
    BigDecimal miscFeesCny;          // 其他费（人民币）

    // === 广告费 ===
    BigDecimal advertisingCost;      // 广告费（原币）
    BigDecimal advertisingCostCny;   // 广告费（人民币）

    // === 成本 ===
    BigDecimal purchaseAmount;       // 采购金额（人民币）
    BigDecimal totalCost;            // 总成本（人民币）
}
```

## 七、已确认规则

| 序号 | 问题 | 确认结果 |
|------|------|----------|
| 1 | 佣金/服务费统计范围 | **仅 transaction_category = income/refund 的数据** |
| 2 | "其他费"定义 | **transaction_category 不是 income/refund 的数据的 total 字段** |
| 3 | 采购金额 | **移除**，不在当前数据范畴内 |
| 4 | 消费税统计范围 | 仅 income/refund 类型 |
| 5 | 净收入 | 移除，不再计算 |
