# 慕声报税系统 · 产品白皮书（业务篇）

> 本文档介绍系统的业务操作流程，帮助你完成从数据导入到报税汇总的全过程。
> 操作前请先完成《配置篇》中的基础配置，并在顶部选择目标店铺。

---

## 1. 业务全景

整个报税业务分为三个阶段：

```
  数据采集                  数据加工                  结果输出
  ────────                  ────────                  ────────

  ┌──────────┐
  │ 销售数据  │──┐
  └──────────┘  │
  ┌──────────┐  │          ┌──────────┐          ┌──────────┐
  │ 配送数据  │──┼────→     │ 结算推导  │────→     │ 报税汇总  │
  └──────────┘  │          │ 自动计算  │          │ 按季度    │
  ┌──────────┐  │          └────┬─────┘          └──────────┘
  │ FBA货件   │──┤               │
  └──────────┘  │          ┌────▼─────┐
  ┌──────────┐  │          │ 单据生成  │
  │ 广告数据  │──┤          │ PO/DN/   │
  └──────────┘  │          │ 结算/发票 │
  ┌──────────┐  │          └──────────┘
  │ 汇率数据  │──┘
  └──────────┘

  简单说：先把各种数据导进来，系统自动算，最后出单据和报表。
```

## 2. 销售数据

销售数据是报税的核心数据源，来自亚马逊的结算报告。

菜单位置：左侧菜单 → 销售数据

### 2.1 数据导入

系统支持两种来源的销售数据：亚马逊原始报表和 ERP 导出报表。

```
  导入步骤：

  Step 1  选择数据来源
          ┌─────────────────┐  ┌─────────────────┐
          │ ○ 亚马逊原始报表 │  │ ○ ERP导出报表   │
          └─────────────────┘  └─────────────────┘

  Step 2  上传 Excel 文件
          系统自动读取文件表头和前几行样例数据

  Step 3  选择字段映射模板
          系统根据数据来源自动推荐匹配的模板
          ┌─────────────────────────────────────┐
          │  模板：[美国站-亚马逊原始格式 ▼]     │
          └─────────────────────────────────────┘

  Step 4  预览确认
          系统按模板解析数据，展示前 10 行预览
          确认数据解析正确后再导入
          ┌──────┬──────────┬──────┬──────────┐
          │ 订单号│ 交易时间  │ 类型 │ 销售金额  │
          ├──────┼──────────┼──────┼──────────┤
          │ 123..│ 2025-01..│ 收入 │ $125.00  │
          │ 456..│ 2025-01..│ 收入 │ $89.50   │
          └──────┴──────────┴──────┴──────────┘

  Step 5  确认导入
          点击后系统开始处理，页面显示实时进度条
          ████████████░░░░ 75%  (1125/1500行)
```

> 导入完成后会自动生成一条导入记录，可在"基础配置 → 导入记录"中查看。

### 2.2 数据列表

导入完成后，在"数据列表"页面查看和管理销售数据。

```
  ┌──────────────────────────────────────────────────────────┐
  │  销售数据列表                                             │
  │  筛选：站点 [全部▼]  日期 [____]~[____]  [搜索] [导出]   │
  ├──────────┬──────┬──────┬──────────┬──────────────────────┤
  │ 订单号    │ 站点 │ 类型  │ 销售金额  │ 交易时间            │
  ├──────────┼──────┼──────┼──────────┼──────────────────────┤
  │ 123-456  │ US   │ 收入  │ $125.00  │ 2025-01-15          │
  │ 789-012  │ US   │ 退款  │ -$30.00  │ 2025-01-18          │
  │ ...      │ ...  │ ...  │ ...      │ ...                  │
  ├──────────┴──────┴──────┴──────────┴──────────────────────┤
  │  汇总：总收入 $50,000  退款 -$3,200  净收入 $46,800       │
  └──────────────────────────────────────────────────────────┘

  支持的操作：
  · 按站点、日期、交易类型、订单号筛选
  · 查看汇总统计（页面底部）
  · 导出为 Excel
  · 单条删除 / 批量删除 / 按导入批次整批删除
```

## 3. 配送数据

配送数据记录亚马逊物流的配送费用明细。

菜单位置：左侧菜单 → 配送数据

### 3.1 数据导入

配送数据的导入比销售数据简单，直接上传文件即可。

```
  导入步骤：

  Step 1  拖拽文件到上传区域（支持同时上传多个文件）
          ┌─────────────────────────────────────┐
          │  📄 拖拽文件到此处                    │
          │     支持 Excel / CSV                 │
          └─────────────────────────────────────┘

  Step 2  确认文件列表
          ✅ shipping_US_202501.xlsx
          ✅ shipping_US_202502.xlsx
          ✅ shipping_US_202503.xlsx

  Step 3  点击 [开始导入]
          系统自动解析并入库
```

### 3.2 数据列表

支持按站点、日期范围筛选，提供汇总统计和 Excel 导出。操作方式与销售数据列表一致。

```
          ✅ FBA_shipment_20250315.xlsx
```

## 5. 广告数据

广告数据记录亚马逊广告投放的费用，按发票维度管理。

菜单位置：左侧菜单 → 广告数据

### 5.1 广告费录入

广告数据采用手动录入方式，按发票逐条填写。

```
  │ 发票编号：[INV-2025-001        ]            │
  │ 站点：    [US ▼]                            │
  │ 账单周期：[2025-01-01] ~ [2025-01-31]       │
  │ 总金额：  [$1,250.00          ]             │
  │                                              │
  │ 活动明细（可添加多条）：                      │
  │ ┌──────────┬──────────┬──────────┐          │
  │ │ 活动ID    │ 活动名称  │ 花费     │          │
  │ ├──────────┼──────────┼──────────┤          │
  │ │ CP-001   │ 品牌推广  │ $500.00  │          │
  │ │ CP-002   │ 商品推广  │ $750.00  │          │
  │ └──────────┴──────────┴──────────┘          │
  │                                              │

  └─────────────────────────────────────────────┘
```

### 5.2 数据列表

## 6. FBA 单据管理

这是系统的核心输出模块——把前面导入的各种数据，加工成报税所需的正式单据。

菜单位置：左侧菜单 → FBA单据管理

### 6.1 结算推导

根据已导入的销售、配送、FBA、广告数据，结合汇率，自动推导出各站点的结算金额。

```
  操作步骤：

  Step 1  选择季度范围
          ┌──────────────────────────────────┐
          │ 季度：[2025-Q1 ▼] ~ [2025-Q1 ▼] │
          └──────────────────────────────────┘

  Step 2  填写各站点的采购成本（人民币）
          ┌──────┬──────────────────┐
          │ 站点 │ 采购成本(¥)      │
          ├──────┼──────────────────┤
          │ US   │ [150,000        ]│
          │ UK   │ [80,000         ]│
          │ DE   │ [60,000         ]│
          │ CA   │ [40,000         ]│
          └──────┴──────────────────┘

  Step 3  点击 [执行推导]
          系统自动计算各站点的：
          · 收入金额（外币 + 人民币）
          · 退款金额（多种口径）
          · 各类费用（佣金、FBA费、服务费等）
          · 采购成本分摊
          · 利润计算
```

> 重新推导会自动覆盖旧数据，不用手动删除。

### 6.2 单据生成

推导完成后，按顺序生成四种正式单据：

```
  生成顺序（必须按此顺序操作）：

  ① PO（采购订单）
     记录从供应商采购商品的订单信息
     │
  ② DN（送货单）
     记录商品从供应商发往亚马逊仓库的物流信息
     │
  ③ 结算单（4份，按站点拆分）
     每个站点一份结算明细
     US站结算单 / UK站结算单 / DE站结算单 / CA站结算单
     │
  ④ INV 发票（4份，基于结算单）
     每份结算单对应一份正式发票
     US站发票 / UK站发票 / DE站发票 / CA站发票
```

每一步点击对应的生成按钮即可，系统会自动关联上一步的数据。

### 6.3 单据列表

所有生成的单据都在这里查看和导出。

```
  ┌──────────┬──────┬──────────┬──────┬──────────────────────┐
  │ 单据编号  │ 类型 │ 结算周期  │ 站点 │ 操作                  │
  ├──────────┼──────┼──────────┼──────┼──────────────────────┤
  │ PO-001   │ PO   │ 2025-Q1  │ 全部 │ [查看] [导出Excel]   │
  │ DN-001   │ DN   │ 2025-Q1  │ 全部 │ [查看] [导出Excel]   │
  │ ST-001   │ 结算 │ 2025-Q1  │ US   │ [查看] [导出Excel]   │
  │ ST-002   │ 结算 │ 2025-Q1  │ UK   │ [查看] [导出Excel]   │
  │ INV-001  │ 发票 │ 2025-Q1  │ US   │ [查看] [导出Excel]   │
  │ INV-002  │ 发票 │ 2025-Q1  │ UK   │ [查看] [导出Excel]   │
  └──────────┴──────┴──────────┴──────┴──────────────────────┘

  导出方式：
  · 单份导出：点击某条记录的 [导出Excel]
  · 批量导出：选择结算周期，一键打包下载全部单据（ZIP 压缩包）
```

### 6.4 MSKU 列表

管理各站点的商家 SKU 信息，可以手动修正单价和采购成本。

```
  ┌──────────┬──────┬──────┬──────────┬──────────┬──────┐
  │ MSKU     │ 货币 │ 数量 │ 单价     │ 采购成本  │ 操作 │
  ├──────────┼──────┼──────┼──────────┼──────────┼──────┤
  │ SKU-A001 │ USD  │ 100  │ $15.00   │ ¥8,500   │ [编辑]│
  │ SKU-A002 │ USD  │ 50   │ $25.00   │ ¥7,200   │ [编辑]│
  └──────────┴──────┴──────┴──────────┴──────────┴──────┘
```

> 修改 MSKU 数据后，需要重新执行结算推导才能生效。

菜单位置：左侧菜单 → 报税汇总

选择季度范围后，系统展示各站点的完整报税数据：

```
  ┌──────┬──────────┬──────────┬──────────┬──────────┬──────────┐
  │ 站点 │ 收入(外币)│ 收入(¥)  │ 退款(¥)  │ 费用(¥)  │ 采购成本  │
  ├──────┼──────────┼──────────┼──────────┼──────────┼──────────┤
  │ US   │ $50,000  │ ¥361,750│ -¥23,152│ -¥45,200│ ¥150,000 │
  │ UK   │ £20,000  │ ¥183,040│ -¥9,800 │ -¥18,300│ ¥80,000  │
  │ DE   │ €15,000  │ ¥117,960│ -¥7,100 │ -¥12,500│ ¥60,000  │
  │ CA   │ C$25,000 │ ¥131,250│ -¥6,500 │ -¥10,800│ ¥40,000  │
  ├──────┼──────────┼──────────┼──────────┼──────────┼──────────┤
  │ 合计 │ -        │ ¥794,000│ -¥46,552│ -¥86,800│ ¥330,000 │
```

报表包含的详细指标：
- 收入（按发货归属）
- 退款（三种口径：按发货归属 / 按结算时间 / Amazon 口径）

- 导出汇总表（Excel）
- 导出统计明细（包含参与计算的原始数据，按收入/退款/费用/其它分 Sheet）

## 9. 完整操作流程

以一个季度的报税为例，按以下顺序操作：

```
  ┌─────────────────────────────────────────────────────┐
  │              季度报税完整操作流程                      │
  │                                                      │
  │  ① 在顶部切换到目标店铺                               │
  │     │                                                │
  │  ② 导入销售数据                                      │
  │     │  销售数据 → 数据导入 → 选来源 → 上传 → 选模板   │
  │     │  → 预览 → 确认导入                              │
  │     │                                                │
  │  ③ 导入配送数据                                      │
  │     │  配送数据 → 数据导入 → 上传文件 → 确认导入       │
  │     │                                                │
  │  ④ 导入 FBA 货件                                     │
  │     │  FBA货件 → 数据导入 → 选站点 → 上传 → 确认导入  │
  │     │                                                │
  │  ⑤ 录入广告费                                        │
  │     │  广告数据 → 广告费录入 → 填写发票信息 → 提交     │
  │     │                                                │
  │  ⑥ 检查汇率                                          │
  │     │  汇率管理 → 确认本季度汇率完整 → 补充缺失的     │
  │     │                                                │
  │  ⑦ 执行结算推导                                      │
  │     │  FBA单据 → 结算推导 → 输入采购成本 → 执行       │
  │     │                                                │
  │  ⑧ 生成单据                                          │
  │     │  FBA单据 → 单据生成                             │
  │     │  依次生成：PO → DN → 结算单(×4) → 发票(×4)     │
  │     │                                                │
  │  ⑨ 导出单据                                          │
  │     │  FBA单据 → 单据列表 → 批量导出 ZIP              │
  │     │                                                │
  │  ⑩ 查看报税汇总                                      │
  │     └  报税汇总 → 选择季度 → 查看/导出报表            │
  └─────────────────────────────────────────────────────┘
```

## 10. 通用操作说明

### 数据导入

所有导入功能共享以下特性：

```
  支持的文件格式：Excel (.xlsx / .xls) 和 CSV (.csv)
  单次导入建议：不超过 5000 行
  文件大小限制：10MB

  导入过程中可以实时查看进度条。
  导入完成后自动生成导入记录，可在"基础配置 → 导入记录"中查看。
  如果部分行导入失败，可以下载错误报告查看具体原因。
```

### 数据导出

```
  导出格式：
  · 默认 Excel (.xlsx)
  · 数据量超过 10 万行时自动切换为 CSV 压缩包

  导出方式：
  · 单条导出：点击操作列的 [导出] 按钮
  · 批量导出：勾选多条后点击 [批量导出]
  · 按周期导出：选择结算周期，一键打包全部关联单据
```

### 数据删除

```
  三种删除方式：
  · 单条删除：点击操作列的 [删除]
  · 批量删除：勾选多条后点击 [批量删除]
  · 按批次删除：删除某次导入的全部数据（在导入记录中操作）

  删除后数据不会立即从数据库清除（逻辑删除），
  管理员可以在系统管理中执行物理删除。
```
