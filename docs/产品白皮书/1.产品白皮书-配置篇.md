# 慕声报税系统 · 产品白皮书（配置篇）

> 系统使用前的基础配置指南，帮助你快速搭建报税工作环境。

---

## 1. 系统简介

慕声报税系统是一套专为亚马逊跨境电商设计的转口贸易报税管理平台。

它解决的核心问题：把散落在各种 Excel 里的销售、配送、FBA、广告数据，自动汇总计算，生成报税所需的全套单据。

```
  散乱的 Excel 数据  ──→  系统自动处理  ──→  报税单据 + 汇总报表
```

## 3. 用户角色

系统有三种角色，权限从大到小：

| 角色 | 能做什么 | 不能做什么 |
|------|---------|-----------|
| 管理员 | 所有操作，包括管理用户和系统配置 | 无限制 |
| 财务 | 导入数据、生成单据、查看报表 | 不能管理用户 |
| 查看者 | 查看数据和报表 | 不能导入、修改、删除任何数据 |

## 4. 店铺选择器（重要概念）

这是使用系统前必须理解的核心概念。

### 为什么需要选择店铺？

慕声可能经营多个店铺，每个店铺的业务数据是独立的。一个店铺可以同时经营多个亚马逊站点（如美国站、英国站等），选择不同的店铺，看到的数据完全不同。

### 怎么操作？

```
  顶部导航栏右侧有一个店铺选择器：

  ┌─────────────────┐
  │ 🏪 慕声北美店 ▼  │  ← 点击展开
  └────────┬────────┘
           │
  ┌────────▼────────┐
  │ ○ 慕声北美店     │  ← 点击切换
  │ ● 慕声欧洲店     │
  └─────────────────┘

  切换后，页面数据自动刷新为该店铺的数据。
  系统会记住你的选择，下次登录自动恢复。
```

> 如果只有一个店铺，系统会自动选中，无需手动操作。

## 5. 基础配置（全局生效）

基础配置是系统运行的基石。这些配置对所有店铺共享，只需设置一次。

菜单位置：左侧菜单 → 基础配置

### 5.1 货币管理

管理系统中用到的货币种类。

```
  需要添加的货币：
  ┌──────┬──────┬──────┐
  │ 编码 │ 名称 │ 符号 │
  ├──────┼──────┼──────┤
  │ USD  │ 美元 │ $    │
  │ GBP  │ 英镑 │ £    │
  │ EUR  │ 欧元 │ €    │
  │ CAD  │ 加元 │ C$   │
  │ CNY  │ 人民币│ ¥    │
  └──────┴──────┴──────┘

  操作：新增 / 编辑 / 删除 / 启用 / 禁用
```

> 货币信息会在站点管理、汇率管理等多处引用，建议首先配置。

### 5.2 站点管理

管理亚马逊各国站点，每个站点关联一种货币。

```
  ┌──────┬──────────┬──────┬──────┐
  │ 代码 │ 站点名称  │ 区域 │ 货币 │
  ├──────┼──────────┼──────┼──────┤
  │ US   │ 美国站   │ 北美  │ USD  │
  │ UK   │ 英国站   │ 欧洲  │ GBP  │
  │ DE   │ 德国站   │ 欧洲  │ EUR  │
  │ CA   │ 加拿大站 │ 北美  │ CAD  │
  └──────┴──────────┴──────┴──────┘
```

### 5.3 店铺管理

店铺是业务数据隔离的最小单位。一个店铺可以经营多个站点的业务，站点信息体现在具体的业务数据中（如销售数据、广告数据等），而非店铺本身。

```
  ┌──────┬──────────────┬──────────┬──────────────────┬────────┐
  │ 编码 │ 店铺名称      │ 卖家ID   │ 公司名称          │ 状态   │
  ├──────┼──────────────┼──────────┼──────────────────┼────────┤
  │ S001 │ 慕声北美店    │ A3XXX... │ 东莞市慕声商贸... │ ✅启用 │
  │ S002 │ 慕声欧洲店    │ A1YYY... │ Hong Kong Andeo..│ ✅启用 │
  └──────┴──────────────┴──────────┴──────────────────┴────────┘

  一个店铺可以覆盖多个站点，例如：
  · "慕声北美店" 同时经营 US（美国站）和 CA（加拿大站）
  · "慕声欧洲店" 同时经营 UK（英国站）和 DE（德国站）

  新增店铺后，顶部店铺选择器会自动出现该店铺。
```

### 5.4 交易类型映射

亚马逊原始数据中的交易类型名称五花八门（英文），需要映射为系统统一的中文分类，系统才能正确归类计算。

```
  映射关系示例：

  亚马逊原始名称              系统分类
  ─────────────              ────────
  "Order"          ──→      收入
  "Refund"         ──→      退款
  "FBA Inventory"  ──→      FBA费用
  "Service Fee"    ──→      服务费
  "Adjustment"     ──→      调整
  "Tax"            ──→      消费税
```

> 如果导入数据时遇到未映射的交易类型，系统会提示你补充映射。

### 5.5 字段映射模板

这是系统最灵活也最重要的配置。

不同来源的 Excel 文件，列名各不相同。字段映射模板告诉系统"你的 Excel 里哪一列对应什么数据"。

```
  举个例子：

  亚马逊原始报表的列名          对应的系统字段
  ──────────────────          ──────────────
  "date/time"          ──→   交易时间
  "settlement id"      ──→   结算ID
  "type"               ──→   交易类型
  "order id"           ──→   订单号
  "product sales"      ──→   销售金额

  而 ERP 导出的报表列名不同：
  "交易日期"            ──→   交易时间
  "结算编号"            ──→   结算ID
  "类型"               ──→   交易类型
```

### 创建映射模板的操作步骤

```
  Step 1  上传一份示例 Excel 文件
          系统自动读取表头，列出所有列名
          │
  Step 2  系统左边显示你的列名，右边显示目标字段
          用鼠标拖拽连线，建立映射关系
          │
          也可以点击 [智能匹配]，系统根据列名
          相似度自动推荐映射（省时省力）
          │
  Step 3  确认映射关系无误后，保存模板
          │
  Step 4  可以设为默认模板，导入数据时自动使用
```

> 同一种数据类型可以创建多个模板。比如销售数据可以有"亚马逊原始格式"和"ERP格式"两个模板。

### 5.6 导入记录

每次数据导入都会自动生成一条记录，方便追溯。

```
  ┌──────────┬──────────┬──────┬──────┬────────┐
  │ 批次号    │ 数据类型  │ 总行 │ 成功 │ 状态   │
  ├──────────┼──────────┼──────┼──────┼────────┤
  │ B20250301│ 销售数据  │ 1500 │ 1498 │ ⚠部分  │
  │ B20250302│ 配送数据  │ 200  │ 200  │ ✅成功 │
  │ B20250303│ FBA货件   │ 50   │ 50   │ ✅成功 │
  └──────────┴──────────┴──────┴──────┴────────┘

  功能：
  · 查看每次导入的成功/失败详情
  · 下载错误报告（标注哪些行失败、失败原因）
  · 对失败的导入执行重试
  · 实时查看正在进行的导入进度
```

## 6. 汇率管理（全局生效）

汇率用于将各站点的外币金额换算为人民币，是报税计算的关键数据。

菜单位置：左侧菜单 → 汇率管理

### 6.1 汇率导入

三种录入方式，按需选择：

```
  方式一：手动录入（少量补充）
  ────────────────────────
  选择货币 → 选择日期 → 输入汇率 → 保存

  方式二：Excel 导入（批量录入）
  ────────────────────────────
  准备好汇率 Excel 文件 → 上传 → 系统自动解析入库

  方式三：中国货币网同步（推荐，最准确）
  ──────────────────────────────────────
  1. 打开中国货币网（www.chinamoney.com.cn）
  2. 找到需要的汇率页面
  3. 按 F12 打开浏览器开发者工具
  4. 切到 Network 标签，找到 CcprHisNew 请求
  5. 右键该请求 → Copy as cURL
  6. 回到系统，粘贴到输入框，点击 [同步汇率]
  7. 系统自动解析并入库
```

### 6.2 汇率查询

支持按货币类型、日期范围筛选查看，也可以导出为 Excel。

## 9. 首次使用配置清单

按照以下顺序完成配置，即可开始使用业务功能：

```
  ✅ Step 1  货币管理 → 添加 USD、GBP、EUR、CAD、CNY
  ✅ Step 2  站点管理 → 添加美国、英国、德国、加拿大站点
  ✅ Step 3  店铺管理 → 创建店铺（一个店铺可覆盖多个站点）
  ✅ Step 4  交易类型映射 → 配置常见交易类型的映射关系
  ✅ Step 5  字段映射模板 → 上传示例文件，创建导入模板
  ✅ Step 6  汇率导入 → 导入所需时间段的汇率数据

  全部完成后，切换到目标店铺，就可以开始导入业务数据了。
  具体业务操作请参阅《产品白皮书-业务篇》。
```
