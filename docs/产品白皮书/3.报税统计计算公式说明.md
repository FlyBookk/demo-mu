# 报税统计计算公式说明

> 版本: v3.1（严格基于代码逻辑，注释不作为依据）
> 日期: 2026-03-08
> 说明: 本文档完全基于 `TaxReportServiceImpl.calculateTaxSummaryFromMemory` 代码执行逻辑整理，供业务方进行结果复核使用。

---

## 一、数据来源与加载范围

| 数据集 | 数据库表 | 加载范围 | 用途 |
|--------|---------|---------|------|
| allShipping（全量配送数据） | shipping_data | 发货日期在 **[季度开始 - 6个月, 季度结束]** 之间 | 收入计算、订单号集合、orderRateMap |
| allSalesData（income/refund） | sales_data | transaction_category IN ('income','refund')，交易日期在 **[季度开始 - 1个月, 季度结束 + 2个月]** | 收入费用、退款、消费税、佣金 |
| allOtherData（其他类型） | sales_data | transaction_category NOT IN ('income','refund')，交易日期在 **[季度开始, 季度结束]** | 其他费用、Amazon口径佣金 |
| allAds（广告数据） | advertising_bill + advertising_bill_item | 账单周期与季度有交集（billingEndDate >= 季度开始 且 billingStartDate <= 季度结束） | 广告费 |

> 注：allShipping 向前扩展6个月，目的是让 orderRateMap 能覆盖上一季度发货订单的汇率，用于退款汇率匹配。

## 二、中间集合的构建

### 2.1 shippingOrderIds（本季度发货订单号集合）

```
从 allShipping 中筛选：
  ship_date 不为 null
  AND ship_date 在 [startDate, endDate] 之间

提取所有 orderId 组成集合
```

### 2.2 allShippingOrderIds（全量配送数据订单号集合）

```
从 allShipping 中提取所有 orderId（不限日期）
包含当前季度 + 前6个月的配送数据中的所有订单号
```

### 2.3 orderRateMap（订单号 → 汇率映射）

```
从 allShipping 中构建：
  key = orderId
  value = shipping.exchangeRate（该订单配送记录的汇率）
  若同一 orderId 有多条配送记录，取最后一条（merge 时保留后者）
```

### 2.4 incomeList（收入记录集合）

```
从 allSalesData 中筛选：
  transaction_category = 'income'
  AND orderId 在 shippingOrderIds 中（本季度发货订单）
```

### 2.5 refundList（退款记录集合，用于维度一/二）

```
从 allSalesData 中筛选：
  transaction_category = 'refund'
  AND orderId 在 allShippingOrderIds 中（全量配送数据，含前6个月）
```

### 2.6 refundListAmazon（Amazon口径退款集合）

```
从 allSalesData 中筛选：
  transaction_category = 'refund'
  AND transaction_date 不为 null
  AND transaction_date 在 [startDate, endDate] 之间
（不要求 orderId 在任何配送数据中）
```

## 三、各指标计算公式

### 3.1 收入总额

**数据源**：allShipping

**筛选**：ship_date 在 [startDate, endDate] 之间

**单条金额（原币）**：
```
若 total_amount 字段不为 null 且不为 0 → 直接使用 total_amount
否则 → 计算以下8项之和（null 视为 0）：
  productPrice + productTax
  + shippingPrice + shippingTax
  + giftWrapPrice + giftWrapTax
  + productPromotionDiscount + shipmentPromotionDiscount
```

**汇率**：直接使用该配送记录的 `shipping.exchangeRate`（无 orderRateMap 回退）

```
收入总额（原币）= Σ 单条金额（原币）
收入总额（人民币）= Σ 单条金额（原币）× shipping.exchangeRate
  若 exchangeRate 为 null 或 ≤ 0，则按 1:1 换算（即直接加原币值）
```

---

### 3.2 退款金额（三个维度）

**退款金额计算公式（每条记录，原币）**：
```
退款金额 = productSales + productSalesTax
         + shippingCredits + shippingCreditsTax
         + giftWrapCredits + giftWrapCreditsTax
         + promotionalRebates + promotionalRebatesTax
（所有字段 null 视为 0，结果保留原正负）
```

**汇率（三个维度通用）**：
```
rate = orderRateMap.get(orderId)  // 优先：该订单配送记录的汇率
     ?? refund.exchangeRate        // 次选：退款记录自带汇率
     ?? 1.0                        // 兜底
（rate ≤ 0 时也使用 1.0）
```

---

#### 维度一：按结算时间（refundBySettlement）

**数据源**：refundList（orderId 在全量配送数据中）

**筛选**：transaction_date 不为 null AND transaction_date 在 [startDate, endDate] 之间

```
refundBySettlement（原币）= Σ 满足条件记录的 退款金额
refundBySettlementCny（人民币）= Σ 退款金额 × rate
refundCountBySettlement = 满足条件的记录数
```

---

#### 维度二：按发货归属（refundByShipment）

**数据源**：refundList（orderId 在全量配送数据中）

**筛选**：refundShipDateMap.get(orderId) 不为 null AND 该发货日期在 [startDate, endDate] 之间

```
refundByShipment（原币）= Σ 满足条件记录的 退款金额
refundByShipmentCny（人民币）= Σ 退款金额 × rate
refundCountByShipment = 满足条件的记录数
```

> 注：refundShipDateMap 来自 allShipping（含前6个月），因此能匹配上一季度发货的订单。

---

#### 维度三：Amazon口径退款（refundBySettlementAmazon）⭐ 采购成本计算使用此维度

**数据源**：refundListAmazon（不限 orderId，仅要求交易日期在季度内）

```
refundBySettlementAmazon（原币）= Σ 所有记录的 退款金额
refundBySettlementAmazonCny（人民币）= Σ 退款金额 × rate
refundCountBySettlementAmazon = 总记录数
```

---

### 3.3 消费税（平台代扣税）

**数据源**：incomeList + refundList 中维度二命中的记录（发货日期在季度内）

```
income 部分：
  遍历 incomeList（本季度发货订单的 income 记录）
  rate = orderRateMap.get(orderId) ?? income.exchangeRate ?? 1.0
  incomeConsumptionTax += marketplaceWithheldTax（null 视为 0）
  incomeConsumptionTaxCny += marketplaceWithheldTax × rate

refund 部分：
  遍历 refundList，仅取发货日期在 [startDate, endDate] 内的记录（维度二命中）
  rate = orderRateMap.get(orderId) ?? refund.exchangeRate ?? 1.0
  refundConsumptionTax += marketplaceWithheldTax（null 视为 0）
  refundConsumptionTaxCny += marketplaceWithheldTax × rate

消费税合计（原币）= incomeConsumptionTax + refundConsumptionTax
消费税合计（人民币）= incomeConsumptionTaxCny + refundConsumptionTaxCny
（结果保留原正负，通常为负值）
```

---

### 3.4 佣金/服务费（两套口径）

#### 口径一：内部口径（totalServiceFee）

**数据源**：incomeList + refundList 中维度二命中的记录

**各明细字段计算**（income 和 refund 维度二各自累加后相加）：

```
sellingFees（原币）= Σ income.sellingFees + Σ refund(维度二).sellingFees
fbaFees（原币）= Σ income.fbaFees + Σ refund(维度二).fbaFees
otherTransactionFees（原币）= Σ income.otherTransactionFees + Σ refund(维度二).otherTransactionFees
otherAmount（原币）= Σ income.other + Σ refund(维度二).other

汇率：orderRateMap.get(orderId) ?? record.exchangeRate ?? 1.0

totalServiceFee（原币）= sellingFees + fbaFees + otherTransactionFees + otherAmount
totalServiceFeeCny（人民币）= sellingFeesCny + fbaFeesCny + otherTransactionFeesCny + otherAmountCny
```

#### 口径二：Amazon口径（totalCommissionFee）⭐ 采购成本计算使用此口径

**数据源**：allSalesData（income+refund，不限 orderId）+ allOtherData，均按交易日期在 [startDate, endDate] 内筛选

```
遍历 allSalesData（income+refund）：
  筛选：transaction_date 在 [startDate, endDate] 之间
  commGbp = sellingFees + fbaFees + otherTransactionFees（null 视为 0）
  rate = orderRateMap.get(orderId) ?? sale.exchangeRate ?? 1.0
  totalCommissionFee += commGbp
  totalCommissionFeeCny += commGbp × rate

遍历 allOtherData（其他类型）：
  筛选：transaction_date 在 [startDate, endDate] 之间
  commGbp = sellingFees + fbaFees + otherTransactionFees（null 视为 0）
  rate = otherItem.exchangeRate ?? 1.0（无 orderRateMap 回退）
  totalCommissionFee += commGbp
  totalCommissionFeeCny += commGbp × rate

（不含 other 字段，不含 marketplaceWithheldTax）
```

---

### 3.5 其他费用

**数据源**：allOtherData（transaction_category NOT IN ('income','refund')）

**筛选**：transaction_date 在 [startDate, endDate] 之间，且 total 字段不为 null 且不为 0

**汇率**：直接使用 `other.exchangeRate`（无 orderRateMap 回退），null 或 ≤ 0 时用 1.0

**按 transaction_type 拆分**：

```
若 transaction_type = 'ServiceFee'（大小写不敏感）：
  miscServiceFee（原币）+= total
  miscServiceFeeCny（人民币）+= total × rate

否则（其他所有类型）：
  otherFees（原币）+= total
  otherFeesCny（人民币）+= total × rate

miscFeesCount = 两类记录总数（total ≠ 0 的记录）
```

> 注：此处使用 `total` 字段（整条记录合计），不拆分 sellingFees/fbaFees 等子字段。

---

### 3.6 广告费

**数据源**：allAds，筛选条件：账单周期（billingStartDate ~ billingEndDate）与季度有交集

**交集判断**：
```
有交集 = NOT (billingEndDate < startDate OR billingStartDate > endDate)
即：billingEndDate >= startDate AND billingStartDate <= endDate
特殊情况：
  若 billingStartDate 和 billingEndDate 均为 null → 不纳入
  若仅 billingStartDate 不为 null → billingStartDate <= endDate 则纳入
  若仅 billingEndDate 不为 null → billingEndDate >= startDate 则纳入
```

**金额计算**：
```
advertisingCost（原币）= Σ item.cost（null 跳过）

advertisingCostCny（人民币）：
  若 item.amountCny 不为 null → 直接使用 amountCny
  否则：
    若 currency = 'CNY' → 直接使用 cost
    否则 → 按 bill.issueDate（发票开具日期）查汇率表换算
    （换算失败时该条记录的人民币金额为 0，记录 warn 日志）
```

## 四、汇总计算公式

### 4.1 总成本（totalCost）

```
totalCost（人民币）= totalServiceFeeCny（内部口径佣金）
                  + miscServiceFeeCny（ServiceFee类其他费）
                  + otherFeesCny（其他类其他费）
                  + advertisingCostCny（广告费）
```

### 4.2 收入净额（内部变量，不输出）

```
netRevenueCny = totalRevenueCny − |refundBySettlementAmazonCny|
```

### 4.3 平台支出合计（platformExpensesCny）

```
platformExpensesCny = |consumptionTaxCny|
                    + |totalCommissionFeeCny|（Amazon口径）
                    + |advertisingCostCny|

注：platformExpenses（原币字段）固定输出 0，仅人民币字段有值
```

### 4.4 4%利润（profit4PercentCny）

```
profit4PercentCny = netRevenueCny × 4%

注：profit4Percent（原币字段）固定输出 0，仅人民币字段有值
```

### 4.5 采购成本（procurementCostCny）

```
procurementCostCny = netRevenueCny − platformExpensesCny − profit4PercentCny

展开：
  = (totalRevenueCny − |refundBySettlementAmazonCny|)
    − (|consumptionTaxCny| + |totalCommissionFeeCny| + |advertisingCostCny|)
    − (netRevenueCny × 4%)

注：procurementCost（原币字段）固定输出 0，仅人民币字段有值
```

## 六、三个退款维度的差异说明

```
维度一（refundBySettlement）：
  来源：refundList（orderId 必须在全量配送数据中）
  条件：交易日期在季度内
  含义：本季度内结算的退款，但原订单必须有配送记录

维度二（refundByShipment）：
  来源：refundList（orderId 必须在全量配送数据中）
  条件：该订单的发货日期在季度内
  含义：本季度发货的订单所产生的退款（退款可发生在任意时间）

维度三（refundBySettlementAmazon）：
  来源：allSalesData 中 category=refund 的全部记录
  条件：交易日期在季度内，不要求 orderId 在配送数据中
  含义：本季度内所有退款交易，与 Amazon 结算报告口径一致
```

**三者的数据范围关系**：
- 维度三 ≥ 维度一（维度三不限 orderId，范围更大）
- 维度一 与 维度二 无固定大小关系（取决于退款时间分布）
- 消费税和内部口径佣金使用维度二的数据范围
- 采购成本计算使用维度三（Amazon口径）

## 七、复核验证 SQL 参考

以下 SQL 为近似验证，精确结果以系统输出为准（系统使用 orderRateMap 优先匹配配送汇率，SQL 中使用记录自带汇率近似）。

### 7.1 收入总额

```sql
SELECT SUM(total_amount * IFNULL(exchange_rate, 1)) AS revenue_cny
FROM shipping_data
WHERE site_code = 'UK'
  AND ship_date BETWEEN '2025-07-01' AND '2025-09-30';
```

### 7.2 退款金额（Amazon口径）

```sql
SELECT COUNT(*) AS cnt,
       SUM((
         IFNULL(product_sales, 0) + IFNULL(product_sales_tax, 0)
         + IFNULL(shipping_credits, 0) + IFNULL(shipping_credits_tax, 0)
         + IFNULL(gift_wrap_credits, 0) + IFNULL(gift_wrap_credits_tax, 0)
         + IFNULL(promotional_rebates, 0) + IFNULL(promotional_rebates_tax, 0)
       ) * IFNULL(exchange_rate, 1)) AS refund_amazon_cny
FROM sales_data
WHERE transaction_category = 'refund'
  AND site_code = 'UK'
  AND transaction_date BETWEEN '2025-07-01' AND '2025-09-30 23:59:59';
```

### 7.3 佣金合计（Amazon口径）

```sql
SELECT SUM(
  (IFNULL(selling_fees, 0) + IFNULL(fba_fees, 0) + IFNULL(other_transaction_fees, 0))
  * IFNULL(exchange_rate, 1)
) AS commission_amazon_cny
FROM sales_data
WHERE site_code = 'UK'
  AND transaction_date BETWEEN '2025-07-01' AND '2025-09-30 23:59:59';
```

### 7.4 消费税（近似，income 部分）

```sql
SELECT SUM(IFNULL(marketplace_withheld_tax, 0) * IFNULL(exchange_rate, 1)) AS consumption_tax_cny
FROM sales_data sd
INNER JOIN shipping_data sh ON sd.order_id = sh.order_id
  AND sh.site_code = 'UK'
  AND sh.ship_date BETWEEN '2025-07-01' AND '2025-09-30'
WHERE sd.transaction_category = 'income'
  AND sd.site_code = 'UK';
```

### 7.5 其他费用（ServiceFee 类）

```sql
SELECT SUM(IFNULL(total, 0) * IFNULL(exchange_rate, 1)) AS misc_service_fee_cny
FROM sales_data
WHERE transaction_category NOT IN ('income', 'refund')
  AND transaction_type = 'ServiceFee'
  AND site_code = 'UK'
  AND total != 0
  AND transaction_date BETWEEN '2025-07-01' AND '2025-09-30 23:59:59';
```

## 八、注意事项

1. **收入汇率无回退**：收入计算直接使用配送记录的 `exchange_rate`，若该字段为 null 或 ≤ 0，则按 1:1 换算（不查 orderRateMap）。

2. **退款汇率有回退**：退款计算优先用 orderRateMap（配送记录汇率），其次用退款记录自带汇率，最后兜底 1.0。

3. **其他费汇率无回退**：其他费（miscServiceFee/otherFees）直接使用记录自带 `exchange_rate`，无 orderRateMap 回退。

4. **原币字段为 0 的情况**：platformExpenses、profit4Percent、procurementCost 三个原币字段固定输出 0，仅对应的人民币字段（加 Cny 后缀）有实际计算值。

5. **广告费按账单周期交集**：广告费不是按广告发生日期，而是按账单周期（billingStartDate ~ billingEndDate）与统计季度是否有交集来判断，跨季度的广告账单会被完整计入。

6. **allShipping 扩展范围**：配送数据向前扩展6个月加载，目的是让 orderRateMap 和 refundShipDateMap 能覆盖上一季度发货的订单，从而正确匹配退款汇率和发货归属。
