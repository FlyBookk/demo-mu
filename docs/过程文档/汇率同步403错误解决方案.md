# 汇率同步 403 错误解决方案

## 问题描述

中国外汇交易中心（chinamoney.com.cn）使用了反爬虫机制，直接通过程序访问会返回 403 Forbidden 错误。

## 解决方案

### 方案一：配置有效的 Cookie（推荐用于开发测试）

1. **获取 Cookie**

   - 打开浏览器访问 https://www.chinamoney.com.cn/chinese/bkccpr/
   - 打开开发者工具（按 F12 或右键 -> 检查）
   - 切换到 Network（网络）标签页
   - 在页面上查询汇率数据，找到名为 `CcprHisNew` 的请求
   - 点击该请求，在右侧面板找到 "Request Headers"（请求头）
   - 复制 `Cookie` 字段的完整值

2. **配置到系统**

   编辑 `application.yml` 文件：

   ```yaml
   china-money:
     enable-cookie: true
     cookie: "你复制的Cookie值"
     timeout: 30000
   ```

3. **Cookie 注意事项**

   - Cookie 有时效性，通常几小时到几天后会过期
   - Cookie 过期后需要重新获取并更新配置
   - 建议定期更新 Cookie（每天或每周）

### 方案二：使用其他汇率数据源（推荐用于生产环境）

考虑使用官方 API 或其他可靠的汇率数据源：

1. **中国人民银行官方 API**（如果有开放接口）
2. **第三方汇率服务**
   - Exchange Rates API (https://exchangeratesapi.io/)
   - Open Exchange Rates (https://openexchangerates.org/)
   - Fixer.io (https://fixer.io/)
3. **手动导入**
   - 使用现有的导入功能，定期从 Excel 导入汇率数据

### 方案三：使用无头浏览器（适合长期自动化）

使用 Selenium WebDriver 或 Playwright 来模拟真实浏览器：

```java
// 需要添加依赖
// <dependency>
//     <groupId>org.seleniumhq.selenium</groupId>
//     <artifactId>selenium-java</artifactId>
// </dependency>

WebDriver driver = new ChromeDriver(options);
driver.get("https://www.chinamoney.com.cn/chinese/bkccpr/");
// ... 获取数据
```

## 当前配置

系统已经实现了以下改进：

1. **完整的浏览器请求头模拟**
   - User-Agent、Accept、Referer 等标准头
   - sec-ch-ua 等 Chrome 特有的请求头
   - 时间戳参数防止缓存

2. **可配置的 Cookie 支持**
   - 可以通过配置文件启用/禁用 Cookie
   - 支持动态更新 Cookie 值

3. **错误处理优化**
   - 403 错误时返回清晰的错误信息
   - 建议用户检查 Cookie 配置

## 快速测试

配置好 Cookie 后，可以通过以下接口测试：

```bash
# 同步最近7天的汇率
POST http://localhost:8080/api/v1/business/rates/sync/recent?days=7

# 同步指定日期范围的汇率
POST http://localhost:8080/api/v1/business/rates/sync
  ?startDate=2026-01-14
  &endDate=2026-01-20
```

## 故障排查

如果仍然出现 403 错误：

1. **检查 Cookie 是否有效**
   - Cookie 可能已过期，需要重新获取
   - 确认配置文件中的 Cookie 值完整无误

2. **检查网络连接**
   - 确认服务器能访问 chinamoney.com.cn
   - 检查是否有防火墙或代理限制

3. **查看日志**
   - 检查应用日志中的详细错误信息
   - 确认请求头是否正确设置

4. **IP 限制**
   - 如果短时间内请求过多，可能会被临时封禁
   - 建议增加请求间隔或使用代理IP

## 建议

对于生产环境，建议：

1. **使用官方 API** - 如果中国外汇交易中心提供官方 API，申请使用
2. **考虑备用数据源** - 准备多个汇率数据源，提高系统可靠性
3. **定时手动导入** - 对于非实时要求，可以每天手动导入汇率数据
4. **监控和告警** - 配置汇率同步失败的监控告警机制
