# 广告模块优化流程文档

## 1. 项目背景

### 1.1 变更说明
广告模块原始数据格式发生变更，需要调整前后端交互逻辑、数据库表结构及相关业务处理。

### 1.2 参考文档
- **原始数据样例**：`利润报表-广告发票记录-872100874146775040.xlsx`
- **前端 Agent 规则**：`.claude/agents/agent-frontend.md`
- **后端 Agent 规则**：`.claude/agents/agent-backend.md`
- **测试 Agent 规则**：`.claude/agents/agent-test.md`

## 2. 核心变更需求

### 2.1 数据结构调整
1. **账单周期字段改造**
   - **原设计**：单一时间字段
   - **新设计**：双时间字段
     - `billing_start_date`：账单开始时间
     - `billing_end_date`：账单结束时间
   - **数据类型**：DATE 或 DATETIME
   - **必填性**：两个字段均为必填

2. **数据去重规则**
   - **去重字段**：发票编号（invoice_number）
   - **去重策略**：默认保留第一条记录
   - **实施位置**：后端数据导入层

### 2.2 模板设计要求
- 根据 `利润报表-广告发票记录-872100874146775040.xlsx` 的字段结构设计新模板
- 模板需包含所有必要字段（包括新增的双时间字段）
- 模板需提供明确的字段说明和填写示例

## 6. 风险与注意事项

### 6.1 数据迁移风险
- **风险**：如存在历史数据，可能需要数据迁移
- **应对**：
  - 备份原始数据表
  - 编写数据迁移脚本并在测试环境验证
  - 提供回滚方案

### 6.2 接口兼容性
- **风险**：接口字段变更可能影响旧版本客户端
- **应对**：
  - 使用版本控制（如 API v2）
  - 或保持字段向下兼容，新增字段不影响旧逻辑

### 6.3 去重策略变更
- **风险**：去重规则变更可能导致数据丢失
- **应对**：
  - 在导入前明确提示用户去重规则
  - 提供导入预览功能
  - 记录被去重的数据日志
