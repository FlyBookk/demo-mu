### 3.2 推导结论

```
退款金额(GBP) = |productSales + productSalesTax
               + postageCredits + shippingCreditsTax
               + giftWrapCredits + giftWrapCreditsTax
               + promotionalRebates + promotionalRebatesTax|

退款(CNY) = 退款(GBP) × ExchangeRate

退款总额(CNY) = Σ 每条Refund记录的退款(CNY)
```

**关键要素**:
- 包含**全部8个收入组件**（含税、运费、折扣）
- **不含**: marketplaceWithheldTax、sellingFees、fbaFees、otherTransactionFees、other
- **统计范围**: 结算文件中全部 type=Refund 记录，不限制订单号必须在配送数据中
- **日期维度**: 按结算时间(transactionDate在季度内)，而非按配送日期过滤
- **汇率**: 配送日期汇率(顺延) > 交易日期汇率(顺延) > fallback(1.0)
- **公式可信度**: GBP金额确认正确，CNY误差来自汇率来源差异

### 4.2 推导结论

```
佣金(GBP) = sellingFees + fbaFees + otherTransactionFees

【不含】marketplaceWithheldTax (平台代扣税，独立统计)
【不含】other (杂项金额，独立统计)

佣金(CNY) = 佣金(GBP) × ExchangeRate
佣金总额(CNY) = |Σ 每条记录的佣金(CNY)|
```

**关键要素**:
- 包含 **sellingFees + fbaFees + otherTransactionFees** 三个字段
- 统计范围: **所有交易类型**（不仅Order和Refund，还包含FBA Customer Return Fee、Amazon Fees、Liquidations等）
- 汇率: 有配送记录的订单用配送日期汇率，其余用交易日期汇率
- **验证精度: 0.87%，高可信度**

## 七、汇率匹配规则

### 7.1 匹配优先级

```
1. 配送日期汇率: orderId → 配送数据 → shipDate → 查汇率表
2. 交易日期汇率: transactionDate → 查汇率表
3. 兜底: rate = 1.0
```

### 7.2 节假日顺延

配送/交易日期无汇率时，向后逐日查找下一个工作日汇率，最大顺延30天。

**退款4.33%误差分析**:
- 逆推Amazon隐含等效汇率为 **9.2635**，低于Q3所有工作日汇率(最低9.4701)

- 误差主要来自逐笔汇率匹配的微小差异
- 公式和统计范围均已确认正确
