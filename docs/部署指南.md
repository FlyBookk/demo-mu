# 慕声报税系统 — 部署指南

> 适用版本：musheng-tax-system 1.0.0-SNAPSHOT  
> 更新日期：2026-03-08

---

## 一、系统架构

```
用户浏览器
    │
    ▼
 Nginx :80
    ├── /        → 前端静态文件（Vue3）
    └── /api/    → 反向代理 → Spring Boot :8888
                                    │
                                    ▼
                              MySQL :3306
                           (musheng_tax 库)
```

- **前端**：Vue 3 + Vite + Ant Design Vue，Nginx 托管静态文件
- **后端**：Spring Boot 3 + Java 17，以 JAR 方式运行，systemd 管理，端口 **8888**
- **数据库**：MySQL 8，数据库名 `musheng_tax`，账号 `root` / 密码 `root`
- **认证缓存**：Caffeine 本地缓存（无需 Redis）
- **文件上传**：本地磁盘 `/opt/musheng/uploads/`
- **运行用户**：`musheng`（密码 `musheng`）

## 三、服务器初始化（首次部署）

### 3.1 执行 install.sh

将 `docs/install.sh` 上传到服务器并以 **root** 执行：

```bash
# 上传脚本
scp docs/install.sh root@<服务器IP>:/root/

# 以 root 执行
ssh root@<服务器IP> "bash /root/install.sh"
```

脚本会自动完成以下步骤（支持重复执行，已完成的步骤自动跳过）：

| 步骤 | 内容 |
|------|------|
| 1 | 创建系统用户 `musheng`（密码 `musheng`），配置 sudo 权限 |
| 2 | 安装 Java 17（`java-17-openjdk`） |
| 3 | 安装 MySQL 8，root 密码设为 `root`，认证插件改为 `mysql_native_password`，创建 `musheng_tax` 库，开放外部访问 |
| 4 | 安装 Nginx |
| 5 | 创建应用目录 `/opt/musheng/`，归属 `musheng` 用户 |
| 6 | 写入 Nginx 配置（`/api/` 反代到 `127.0.0.1:8888`，最大上传 100M） |
| 7 | 注册 systemd 服务 `musheng`（开机自启，崩溃自动重启，日志写入 `/opt/musheng/logs/app.log`），配置日志每天凌晨 2 点清理 30 天前的文件 |
| 8 | 开放防火墙 80/22/3306 端口（firewalld 未运行时跳过，需在阿里云安全组手动开放） |

脚本执行完毕后会自动切换到 `musheng` 用户。

### 3.2 阿里云安全组

在阿里云控制台 → ECS → 安全组 → 入方向，添加以下规则：

| 协议 | 端口 | 授权对象 | 说明 |
|------|------|----------|------|
| TCP | 80 | 0.0.0.0/0 | HTTP 访问 |
| TCP | 22 | 你的 IP | SSH 登录 |
| TCP | 3306 | 你的 IP | MySQL 外部访问（按需开放） |

## 六、一键上传部署

### 6.1 所需信息

执行 `scripts/deploy-local.sh` 前，需要提供：

| 参数 | 说明 | 示例 |
|------|------|------|
| `SERVER_IP` | 阿里云 ECS 公网 IP | `47.xxx.xxx.xxx` |
| `SERVER_USER` | SSH 登录用户（日常用 musheng） | `musheng` |
| `SERVER_PASS` | SSH 密码 | `musheng` |

脚本默认使用密码登录，如已配置 SSH 密钥则无需密码。

### 6.2 执行一键部署

> macOS 需要先安装 sshpass：`brew install hudochenkov/sshpass/sshpass`

```bash
# 直接执行（已内置服务器 IP 和密码）
bash scripts/deploy-local.sh

# 或指定 IP（覆盖默认值）
bash scripts/deploy-local.sh 47.90.151.125
```

脚本会自动：
1. 打包后端 JAR（`mvn clean package -DskipTests`）
2. 打包前端（`npm run build`）
3. 将 JAR、前端 dist、SQL 文件打包上传到服务器 `/opt/musheng/deploy/`
4. 在服务器上执行 `deploy-server.sh` 完成部署

### 6.3 手动上传（不用脚本）

```bash
SERVER=<服务器IP>

# 上传后端 JAR
scp musheng-tax-system/musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar \
    musheng@${SERVER}:/opt/musheng/backend/

# 上传前端静态文件
scp -r musheng-tax-web/dist/* \
    musheng@${SERVER}:/opt/musheng/frontend/

# 上传数据库 SQL（首次部署）
scp sql/musheng_tax.sql \
    musheng@${SERVER}:/opt/musheng/deploy/

# 在服务器上执行部署脚本
ssh musheng@${SERVER} "bash /opt/musheng/deploy/deploy-server.sh"
```

## 七、服务器端部署脚本（deploy-server.sh）

`scripts/deploy-server.sh` 在服务器上执行，完成：

1. 停止当前运行的 `musheng` 服务
2. 将 JAR 复制到 `/opt/musheng/backend/`
3. 将前端文件复制到 `/opt/musheng/frontend/`
4. 首次部署时导入数据库 SQL（已有表则跳过，幂等）
5. 启动 `musheng` 服务
6. 重载 Nginx

执行方式：

```bash
# 在服务器上（musheng 用户）
bash /opt/musheng/deploy/deploy-server.sh
```

## 八、后续更新

### 只更新后端

```bash
SERVER=<服务器IP>
cd musheng-tax-system && mvn clean package -DskipTests
scp musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar \
    musheng@${SERVER}:/opt/musheng/backend/
ssh musheng@${SERVER} "sudo systemctl restart musheng"
```

### 只更新前端

```bash
SERVER=<服务器IP>
cd musheng-tax-web && npm run build
scp -r dist/* musheng@${SERVER}:/opt/musheng/frontend/
ssh musheng@${SERVER} "sudo systemctl reload nginx"
```

## 九、常用运维命令

```bash
# ── 后端服务 ──────────────────────────────
sudo systemctl start   musheng    # 启动
sudo systemctl stop    musheng    # 停止
sudo systemctl restart musheng    # 重启
sudo systemctl status  musheng    # 查看状态

# ── 日志 ──────────────────────────────────
tail -f /opt/musheng/logs/app.log          # 实时跟踪
tail -n 200 /opt/musheng/logs/app.log      # 最近 200 行
grep ERROR /opt/musheng/logs/app.log       # 过滤错误

# ── Nginx ─────────────────────────────────
sudo nginx -t                     # 检查配置
sudo systemctl reload  nginx      # 热重载
sudo systemctl restart nginx      # 完全重启

# ── MySQL ─────────────────────────────────
systemctl status mysqld
mysql -u root -proot              # 进入 MySQL
mysql -u root -proot musheng_tax  # 进入业务库
```
