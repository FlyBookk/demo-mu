# 慕声报税系统 — 部署指南

> 适用版本：musheng-tax-system 1.0.0-SNAPSHOT
> 更新日期：2026-03-07

---

## 一、系统架构

```
用户浏览器
    │
    ▼
 Nginx :80
    ├── /        → 前端静态文件（Vue3）
    └── /api/    → 反向代理 → Spring Boot :8080
                                    │
                                    ▼
                              MySQL :3306
                           (musheng_tax 库)
```

- **前端**：Vue 3 + Vite + Ant Design Vue，Nginx 托管静态文件
- **后端**：Spring Boot 3 + Java 17，以 JAR 方式运行，systemd 管理
- **数据库**：MySQL 8，数据库名 `musheng_tax`
- **认证缓存**：Caffeine 本地缓存（无需 Redis）
- **文件上传**：本地磁盘 `/opt/musheng/uploads/`

---

## 二、所需组件

| 组件 | 版本 | 安装位置 | 备注 |
|------|------|----------|------|
| Java (OpenJDK) | **17+** | 服务器 | 运行后端 JAR |
| MySQL | **8.0+** | 服务器 | 业务数据库 |
| Nginx | **1.18+** | 服务器 | 静态文件 + 反代 |
| Maven | 3.8+（仅构建机） | 本地开发机 | 打包后端 |
| Node.js / npm | 18+（仅构建机） | 本地开发机 | 打包前端 |

> Redis **不需要安装**（默认使用 Caffeine 本地缓存）

---

## 三、一键部署（推荐）

在**本地开发机**上执行，脚本会自动构建、上传、安装组件、初始化数据库：

```bash
# 基本用法（密码登录）
MUSHENG_DB_PASSWORD=YourStr0ngPass \
  bash scripts/deploy-local.sh <服务器公网IP> root

# 密钥登录
MUSHENG_DB_PASSWORD=YourStr0ngPass \
SSH_KEY=~/.ssh/aliyun.pem \
  bash scripts/deploy-local.sh <服务器公网IP> root
```

脚本执行流程：
1. 本地 Maven 打包后端 JAR
2. 本地 npm 构建前端 dist
3. 打包并上传到服务器 `/tmp/musheng-deploy/`
4. 服务器安装 Java 17 / MySQL 8 / Nginx
5. 初始化数据库并导入 `musheng_tax.sql`
6. 部署 JAR 和前端静态文件到 `/opt/musheng/`
7. 配置 systemd 服务（开机自启）
8. 配置 Nginx 反向代理

## 四、手动部署（分步）

### 4.1 服务器目录结构

```
/opt/musheng/
├── backend/
│   ├── musheng-web-1.0.0-SNAPSHOT.jar
│   └── application-prod.yml          # 生产环境配置（覆盖默认配置）
├── frontend/                          # 前端 dist 内容
│   ├── index.html
│   └── assets/
└── uploads/
    ├── chunks/                        # 分片上传临时目录
    ├── files/                         # 最终文件目录
    └── temp/                          # 临时目录
```

### 4.2 本地构建

```bash
# 构建后端
cd musheng-tax-system
mvn clean package -DskipTests
# 产物：musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar

# 构建前端
cd musheng-tax-web
npm ci
npm run build
# 产物：dist/
```

### 4.3 上传文件

```bash
# 上传后端 JAR
scp musheng-tax-system/musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar \
    root@<服务器IP>:/opt/musheng/backend/

# 上传前端静态文件
scp -r musheng-tax-web/dist/* \
    root@<服务器IP>:/opt/musheng/frontend/

# 上传 SQL（首次部署）
scp musheng-tax-system/sql/musheng_tax.sql \
    root@<服务器IP>:/opt/musheng/
```

### 4.4 数据库初始化（首次部署）

```bash
# 在服务器上执行
mysql -u root -p <<EOF
CREATE DATABASE IF NOT EXISTS musheng_tax
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'musheng'@'localhost' IDENTIFIED BY 'YourPassword';
GRANT ALL PRIVILEGES ON musheng_tax.* TO 'musheng'@'localhost';
FLUSH PRIVILEGES;
EOF

mysql -u musheng -p musheng_tax < /opt/musheng/musheng_tax.sql
```

### 4.5 生产环境配置

创建 `/opt/musheng/backend/application-prod.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/musheng_tax?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: musheng
    password: YourPassword        # ← 替换为实际密码

app:
  upload:
    chunk-dir: /opt/musheng/uploads/chunks
    final-dir:  /opt/musheng/uploads/files
    temp-dir:  /opt/musheng/uploads/temp

logging:
  level:
    root: warn
    com.musheng: info
```

### 4.6 systemd 服务

创建 `/etc/systemd/system/musheng.service`：

```ini
[Unit]
Description=Musheng Tax System
After=network.target mysqld.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/musheng/backend
ExecStart=/usr/bin/java -jar /opt/musheng/backend/musheng-web-1.0.0-SNAPSHOT.jar \
          --spring.profiles.active=prod
Restart=on-failure
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable musheng
systemctl start musheng
```

### 4.7 Nginx 配置

创建 `/etc/nginx/conf.d/musheng.conf`：

```nginx
server {
    listen 80;
    server_name _;    # 替换为域名，如 tax.example.com

    root /opt/musheng/frontend;
    index index.html;

    # 前端 SPA（History 路由模式）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 反向代理后端 API
    location /api/ {
        proxy_pass         http://127.0.0.1:8080/api/;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_send_timeout    300s;
        proxy_read_timeout    300s;
    }

    client_max_body_size 100M;
}
```

```bash
nginx -t
systemctl reload nginx
```

## 五、后续更新部署

### 只更新后端

```bash
# 本地构建
cd musheng-tax-system && mvn clean package -DskipTests

# 上传并重启
scp musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar root@<IP>:/opt/musheng/backend/
ssh root@<IP> "systemctl restart musheng"
```

### 只更新前端

```bash
# 本地构建
cd musheng-tax-web && npm run build

# 上传并刷新
scp -r dist/* root@<IP>:/opt/musheng/frontend/
ssh root@<IP> "systemctl reload nginx"
```

## 六、常用运维命令

```bash
# ── 后端服务 ──────────────────────────────
systemctl status  musheng       # 查看状态
systemctl start   musheng       # 启动
systemctl stop    musheng       # 停止
systemctl restart musheng       # 重启

journalctl -u musheng -f        # 实时日志
journalctl -u musheng -n 200    # 最近 200 行日志

# ── Nginx ─────────────────────────────────
nginx -t                        # 检查配置
systemctl reload  nginx         # 热重载配置
systemctl restart nginx         # 完全重启

# ── MySQL ─────────────────────────────────
systemctl status  mysqld        # CentOS
systemctl status  mysql         # Ubuntu
mysql -u musheng -p musheng_tax # 进入业务库
```

## 八、防火墙

```bash
# CentOS（firewalld）
firewall-cmd --permanent --add-service=http
firewall-cmd --permanent --add-service=ssh
firewall-cmd --reload

# Ubuntu（ufw）
ufw allow 80/tcp
ufw allow 22/tcp
ufw --force enable
```

> 阿里云 ECS 还需在控制台 **安全组** 中放行入方向 **80 端口**（TCP）。
