# 报税汇总计算公式

> 本文档描述报税汇总各指标的计算逻辑，作为开发实现的依据。

---

## 核心概念

### 数据源

| 数据源 | 说明 |
|-------|------|
| 配送货件表（ShippingData） | 亚马逊配送/发货数据，每笔记录对应一个订单的发货信息 |
| 结算报告（SalesData） | 亚马逊结算数据，包含收入、退款、费用等多种交易类型 |

### 配送日期口径

收入、退款、income/refund 类型的费用统一使用**配送日期口径**：
- 以配送货件表的发货日期（shipDate）作为归属季度的判断依据
- 结算报告中的 income/refund 数据通过订单号（orderId）关联配送数据
- 汇率使用配送数据中的发货日期汇率（exchangeRate）

### 费用名称统一说明

不同站点的原始数据表头名称存在差异，但本质是同一笔费用。以下统一用系统字段名称描述。

---

## 一、收入总额

### 数据源
配送货件表（ShippingData）

### 筛选条件
发货日期（shipDate）在目标季度范围内

### 计算公式

```
收入总额 = Σ（收入小计 × 发货日期汇率）

收入小计 = 商品价格(productPrice)
         + 商品税(productTax)
         + 运费(shippingPrice)
         + 运费税(shippingTax)
         + 礼品包装价格(giftWrapPrice)
         + 礼品包装税(giftWrapTax)
         + 商品促销折扣(productPromotionDiscount)
         + 货件促销折扣(shipmentPromotionDiscount)
```

共 **8项** 费用。

---

## 二、退款金额

### 数据源
结算报告（SalesData），交易分类 = refund

### 筛选条件
通过订单号（orderId）关联配送数据，配送日期（shipDate）在目标季度范围内。

### 汇率
配送日期汇率（与筛选条件同源，都来自配送数据）。

### 计算公式

```
退款金额 = Σ（退款小计 × 配送日期汇率）

退款小计 = 产品销售额(productSales)
         + 产品税(productSalesTax)
         + 运费收入(shippingCredits)
         + 运费税(shippingCreditsTax)
         + 礼品包装收入(giftWrapCredits)
         + 礼品包装税(giftWrapCreditsTax)
         + 监管费(regulatoryFee)
         + 监管费税(regulatoryFeeTax)
         + 促销折扣(promotionalRebates)
```

共 **9项** 费用。

---

## 三、收入净额

```
收入净额 = 收入总额 − |退款金额|
```

---

## 四、平台扣费合计

### 数据源
结算报告（SalesData）

### 费用分类

| 费用类别 | 包含费用项 | 系统字段 |
|---------|-----------|---------|
| 佣金服务费 | 销售费用 + FBA费用 + 其他交易费 | sellingFees + fbaFees + otherTransactionFees |
| 其他费 | 其他 | other |
| 税 | 平台代扣税 | marketplaceWithheldTax |

### 统计方式

每类费用按以下两种方式分别统计后叠加：

| 统计方式 | 适用数据 | 筛选条件 | 汇率 |
|---------|---------|---------|------|
| 方式一 | income + refund 类型 | 通过订单号关联配送数据，配送日期在季度内 | 配送日期汇率 |
| 方式二 | 其他类型（排除 Transfer） | 交易日期在季度内 | 交易日期汇率 |

> 方式一说明：先从配送表筛选出发货日期在季度内的订单号集合，再从结算报告中取 income/refund 类型且订单号在该集合中的记录。

### 计算公式

```
佣金服务费 = 方式一(sellingFees + fbaFees + otherTransactionFees)
           + 方式二(sellingFees + fbaFees + otherTransactionFees)

其他费 = 方式一(other) + 方式二(other)

税 = 方式一(marketplaceWithheldTax) + 方式二(marketplaceWithheldTax)

平台扣费合计 = |佣金服务费| + |其他费| + |税|
```

---

## 五、汇率规则汇总

| 数据类型 | 汇率来源 | 说明 |
|---------|---------|------|
| 收入（配送数据） | 发货日期汇率 | 配送表自带 exchangeRate |
| 退款（refund） | 配送日期汇率 | 通过订单号关联配送数据获取 |
| 费用（income/refund 类型） | 配送日期汇率 | 通过订单号关联配送数据获取 |
| 费用（其他类型） | 交易日期汇率 | 结算报告自带 exchangeRate |
