# 报税汇总计算公式

---

## 数据来源

- **收入**：来自配送货件表，以发货日期归属季度
- **退款 / 费用**：来自结算报告，通过订单号关联配送数据

---

## 各指标计算公式

### 一、收入总额

取配送货件表中**发货日期在本季度**的订单，8 项求和后乘以发货日期汇率。

```
收入小计 = 商品价格 + 商品税 + 运费 + 运费税
         + 礼品包装价格 + 礼品包装税费
         + 商品促销折扣 + 货件促销折扣

收入总额 = Σ（收入小计 × 发货日期汇率）
```

---

### 二、退款金额

取结算报告中交易分类 = refund 的记录，支持两种时间维度（搜索栏切换，默认配送日期）：

| 维度 | 筛选条件 | 汇率 |
|------|---------|------|
| 配送日期（默认） | 退款订单的发货日期在本季度 | 发货日期汇率 |
| 结算日期 | 退款记录的结算日期（date/time）在本季度 | 结算日期汇率 |

```
退款小计 = 产品销售额 + 产品税 + 运费收入 + 运费税
         + 礼品包装收入 + 礼品包装税
         + 监管费 + 监管费税 + 促销折扣

退款金额 = Σ（退款小计 × 对应汇率）
```

> 切换退款时间维度后，退款关联的佣金服务费、其他费用、平台代扣税也同步重新计算。

---

### 三、收入净额

```
收入净额 = 收入总额 − |退款金额|
```

---

### 四、平台扣费

每类费用由两部分叠加：

| 方式 | 适用数据 | 筛选条件 | 汇率 |
|------|---------|---------|------|
| 方式一 | 交易分类 = income 或 refund | 订单号关联到本季度配送订单 | 发货日期汇率 |
| 方式二 | 其他交易分类（排除 type = Transfer） | 结算日期在本季度 | 结算日期汇率 |

```
佣金服务费 = 方式一（selling fees + fba fees + other transaction fees）
           + 方式二（selling fees + fba fees + other transaction fees）

其他费用   = 方式一（other）+ 方式二（other）

平台代扣税 = 方式一（marketplace withheld tax）+ 方式二（marketplace withheld tax）
```

---

### 五、广告费

取广告账单中账期与本季度有交集的明细，按账单汇率换算人民币。

---

### 六、汇总公式

```
平台支出合计 = |平台代扣税| + |佣金服务费| + |广告费| + |其他费用|

4% 利润      = 收入净额 × 4%

采购成本     = 收入净额 − 平台支出合计 − 4% 利润
```
