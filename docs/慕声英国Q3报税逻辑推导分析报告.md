### 3.2 推导结论

**Amazon退款金额公式** (每条Refund记录):

```
退款金额(GBP) = |productSales + productSalesTax
               + postageCredits + shippingCreditsTax
               + giftWrapCredits + giftWrapCreditsTax
               + promotionalRebates + promotionalRebatesTax|

退款金额(CNY) = 退款金额(GBP) × ExchangeRate(配送日期)

退款总额(CNY) = Σ 所有type=Refund记录的退款金额(CNY)
```

**关键要素**:
- 包含**全部8个收入组件** (含税、运费、折扣)
- **不含**: marketplaceWithheldTax、sellingFees、fbaFees、otherTransactionFees、other
- 汇率基准: 原始订单的**配送日期**汇率，而非退款交易日期
- 统计范围: Q3期间**所有Refund交易**，不区分原订单配送季度

### 3.3 系统差异根因分析

#### 问题1: 退款统计维度不匹配 (主因, 贡献约¥31,696差异)

**系统现状** (`TaxReportServiceImpl.java:491-498, 604-607`):
```java
// 第一层过滤: 退款订单号必须在配送数据中
allShippingOrderIds.contains(s.getOrderId())

// 第二层过滤: 原订单配送日期必须在季度范围内
if (shipDate != null && !shipDate.isBefore(startDate) && !shipDate.isAfter(endDate))
```

系统使用 **refundByShipment (发货归属维度)**:
- 仅统计原订单在Q3配送的退款
- Q2配送→Q3退款的约270条记录被排除

**Amazon逻辑**:
- 按**结算时间维度**统计Q3内所有退款交易
- 包含Q2配送→Q3退款的订单

#### 问题2: 未匹配订单的汇率回退策略

- 270条退款订单在Q3配送数据中找不到
- 需要Q2配送数据提供原始配送日期
- 或使用退款交易日期作为回退

### 4.2 推导结论

**Amazon佣金/服务费公式**:

```
服务费(GBP) = sellingFees + fbaFees + otherTransactionFees

(注: 各字段保留原正负号，Order为负值/Refund为正值)

服务费(CNY) = Σ 每条记录的服务费(GBP) × ExchangeRate(配送/交易日期)

佣金服务费合计 = |服务费(CNY)|
```

**关键要素**:
- 包含 **sellingFees + fbaFees + otherTransactionFees** 三个字段
- **不含**: marketplaceWithheldTax (平台代扣税，单独统计)
- **不含**: other (杂项金额，如Transfer转账、Adjustment调整等)
- 统计范围: **所有交易类型**的这三个字段 (不仅是Order和Refund)
- 汇率: 有配送记录的订单用配送日期汇率，其余用交易日期汇率

### 4.3 系统当前显示 vs Amazon定义映射

| 系统显示字段 | 系统金额(CNY) | 对应关系 |
|------------|--------------|---------|

## 五、汇率匹配规则

### 5.1 汇率数据概况

```
覆盖范围: 2025-07-31 至 2025-09-30
数据点数: 44条(仅工作日)
缺失日期:
  - 7月1日~7月30日 (Q3前30天完全缺失)
  - 每周六、日 (如8/2-3, 8/9-10, ...)
  - 节假日
```

### 5.2 汇率匹配优先级

```
1. 优先: 配送日期 → 直接查汇率表
2. 顺延: 配送日期无汇率 → 向后逐日查找，直到找到有汇率的工作日
3. 回退: 无配送记录的订单 → 使用交易日期查汇率(同样支持顺延)
```

### 5.3 节假日顺延示例

| 配送日期 | 是否有汇率 | 实际使用日期 | 汇率 |
|---------|----------|------------|------|
| 2025-08-01 (周五) | ✅ | 2025-08-01 | 9.4701 |
| 2025-08-02 (周六) | ❌ | 2025-08-04 (周一) | 9.4919 |
| 2025-08-03 (周日) | ❌ | 2025-08-04 (周一) | 9.4919 |
| 2025-08-04 (周一) | ✅ | 2025-08-04 | 9.4919 |

### 5.4 已知缺陷

**7月1日-7月30日无汇率数据**: Q3配送数据中有5,441条记录(43%)配送日期在此区间，当前使用7/31汇率作为回退，可能引入误差。建议补充完整的7月汇率数据。

| 维度 | Amazon逻辑 | 系统现状 | 是否一致 |
