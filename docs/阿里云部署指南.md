# 慕声报税系统 - 阿里云单机部署指南

> 适用场景：前后端 + MySQL 全部部署在同一台阿里云轻量/ECS 服务器，用于基础展示。

---

## 快速开始（推荐）

**一条命令完成从白机到可访问**（需在本地执行，已安装 Maven、Node.js）：

```bash
MUSHENG_DB_PASSWORD="你的数据库密码" ./scripts/deploy-local.sh <服务器公网IP>
```

脚本会自动：构建前后端 → 上传 → 安装 Java/MySQL/Nginx → 部署应用 → 启动服务。

---

## 一、前置准备

### 1.1 服务器要求

- **系统**：CentOS 7.x / Ubuntu 20.04+ / Alibaba Cloud Linux 3
- **配置**：1 核 2G 及以上
- **安全组**：放行 22（SSH）、80（HTTP）、443（HTTPS，可选）

### 1.2 本地准备

- 已打包好的后端 jar：`musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar`
- 已打包好的前端静态文件：`musheng-tax-web/dist/` 目录
- 数据库初始化脚本：`musheng-tax-system/sql/musheng_tax.sql`

## 二、环境安装

### 2.1 连接服务器

```bash
ssh root@<你的服务器公网IP>
# 或使用密钥：ssh -i your-key.pem root@<IP>
```

### 2.2 安装 Java 17

```bash
# CentOS / Alibaba Cloud Linux
sudo yum install -y java-17-openjdk java-17-openjdk-devel

# Ubuntu / Debian
sudo apt update
sudo apt install -y openjdk-17-jdk

# 验证
java -version
# 应显示 openjdk version "17.x.x"
```

### 2.3 安装 MySQL 8.0

```bash
# CentOS / Alibaba Cloud Linux
sudo yum install -y mysql-server
sudo systemctl start mysqld
sudo systemctl enable mysqld

# Ubuntu / Debian
sudo apt install -y mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql
```

**获取初始 root 密码（仅首次安装）：**

```bash
# CentOS
sudo grep 'temporary password' /var/log/mysqld.log

# Ubuntu（8.0+ 默认可能无密码，直接 mysql -u root 登录）
sudo mysql -u root
```

**修改 root 密码并创建应用库：**

```bash
mysql -u root -p
# 输入上面查到的临时密码或当前密码

# 在 MySQL 中执行：
ALTER USER 'root'@'localhost' IDENTIFIED BY '你的MySQL密码';
CREATE DATABASE musheng_tax CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'musheng'@'localhost' IDENTIFIED BY '应用数据库密码';
GRANT ALL PRIVILEGES ON musheng_tax.* TO 'musheng'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

**导入表结构：**

```bash
mysql -u musheng -p musheng_tax < /path/to/musheng_tax.sql
# 或使用 root：mysql -u root -p musheng_tax < musheng_tax.sql
```

### 2.4 安装 Nginx

```bash
# CentOS / Alibaba Cloud Linux
sudo yum install -y nginx

# Ubuntu / Debian
sudo apt install -y nginx

sudo systemctl start nginx
sudo systemctl enable nginx
```

### 2.5 安装 Node.js（仅本地构建用，服务器可不装）

若在本地构建，服务器无需安装 Node。若在服务器构建：

```bash
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo yum install -y nodejs
# 或 Ubuntu: curl -fsSL ... | sudo bash - && sudo apt install -y nodejs
```

## 三、应用部署

### 3.1 创建部署目录

```bash
sudo mkdir -p /opt/musheng/{backend,frontend}
sudo chown -R $USER:$USER /opt/musheng
```

### 3.2 上传文件到服务器

**方式一：scp 上传**

在本地项目根目录执行：

```bash
# 上传后端 jar
scp musheng-tax-system/musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar root@<服务器IP>:/opt/musheng/backend/

# 上传前端 dist 目录（先本地构建）
cd musheng-tax-web && npm run build && cd ..
scp -r musheng-tax-web/dist/* root@<服务器IP>:/opt/musheng/frontend/

# 上传 SQL（若尚未导入）
scp musheng-tax-system/sql/musheng_tax.sql root@<服务器IP>:/tmp/
```

**方式二：在服务器上从 Git 拉取并构建**

```bash
# 服务器需安装 git、maven、node
git clone <你的仓库地址> /tmp/musheng
cd /tmp/musheng

# 构建后端
cd musheng-tax-system && mvn clean package -DskipTests
cp musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar /opt/musheng/backend/

# 构建前端
cd ../musheng-tax-web && npm ci && npm run build
cp -r dist/* /opt/musheng/frontend/
```

### 3.3 配置后端

创建应用配置文件（覆盖数据库连接）：

```bash
cat > /opt/musheng/backend/application-prod.yml << 'EOF'
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/musheng_tax?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: musheng
    password: 你的应用数据库密码

app:
  upload:
    chunk-dir: /opt/musheng/uploads/chunks
    final-dir: /opt/musheng/uploads/files
    temp-dir: /opt/musheng/uploads/temp
EOF
```

创建上传目录：

```bash
mkdir -p /opt/musheng/uploads/{chunks,files,temp}
```

### 3.4 配置 Nginx

```bash
sudo tee /etc/nginx/conf.d/musheng.conf << 'EOF'
server {
    listen 80;
    server_name _;   # 可改为你的域名，如 demo.example.com

    root /opt/musheng/frontend;
    index index.html;

    # 前端静态资源
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 文件上传大小限制
    client_max_body_size 100M;
}
EOF
```

检查并重载 Nginx：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

### 3.5 启动后端服务

**方式一：前台运行（测试用）**

```bash
cd /opt/musheng/backend
java -jar musheng-web-1.0.0-SNAPSHOT.jar --spring.profiles.active=prod
```

**方式二：后台运行 + systemd（推荐）**

```bash
sudo tee /etc/systemd/system/musheng.service << 'EOF'
[Unit]
Description=Musheng Tax System
After=network.target mysql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/musheng/backend
ExecStart=/usr/bin/java -jar /opt/musheng/backend/musheng-web-1.0.0-SNAPSHOT.jar --spring.profiles.active=prod
Restart=on-failure
RestartSec=10
Environment="DB_PASSWORD=你的应用数据库密码"

[Install]
WantedBy=multi-user.target
EOF
```

```bash
# 若已在 application-prod.yml 中配置密码，可去掉 Environment 行
sudo systemctl daemon-reload
sudo systemctl start musheng
sudo systemctl enable musheng
sudo systemctl status musheng
```

## 四、本地构建与打包

在部署前，需在本地完成构建。

### 4.1 构建后端

```bash
cd musheng-tax-system
mvn clean package -DskipTests
# 产物：musheng-web/target/musheng-web-1.0.0-SNAPSHOT.jar
```

### 4.2 构建前端

```bash
cd musheng-tax-web
npm ci
npm run build
# 产物：dist/ 目录，确保 .env.production 中 VITE_API_BASE_URL=/api
```

确认 `musheng-tax-web/.env.production` 内容：

```
VITE_APP_TITLE=慕声报税管理系统
VITE_API_BASE_URL=/api
VITE_APP_ENV=production
```

## 五、对外访问

### 5.1 阿里云安全组

1. 登录 [阿里云控制台](https://ecs.console.aliyun.com/)
2. 找到实例 → 安全组 → 配置规则
3. 添加入方向规则：
   - 端口：80，协议：TCP，来源：0.0.0.0/0
   - 端口：22，协议：TCP，来源：你的 IP（建议）或 0.0.0.0/0

### 5.2 防火墙（若启用）

```bash
# CentOS 7 / firewalld
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload

# Ubuntu / ufw
sudo ufw allow 80
sudo ufw allow 22
sudo ufw enable
```

### 5.3 访问地址

- **前端页面**：`http://<服务器公网IP>/`
- **API 文档**：`http://<服务器公网IP>/api/doc.html`（Knife4j）

### 5.4 默认账号

导入 `musheng_tax.sql` 后已包含默认管理员：

- **用户名**：`admin`
- **密码**：`Admin@123`

建议首次登录后立即修改密码。

## 七、故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 502 Bad Gateway | 后端未启动或端口错误 | `systemctl status musheng`，检查 8080 端口 |
| 页面空白 | 前端路由或资源路径错误 | 检查 Nginx `try_files`，确认 dist 部署完整 |
| 接口 404 | context-path 不匹配 | 后端 context-path 为 `/api`，Nginx 代理需一致 |
| 数据库连接失败 | 密码、库名、权限 | 检查 application-prod.yml 与 MySQL 用户权限 |
| 上传失败 | 目录权限 | `chmod 755 /opt/musheng/uploads` 及子目录 |

## 八、自动化部署脚本（推荐）

项目提供一键部署脚本，**从白机到可访问**全自动完成，无需人工逐步操作。

### 8.1 方式一：本地构建 + 远程部署（最省事）

在**本地项目根目录**执行，自动完成：构建 → 上传 → 服务器安装环境 → 部署应用。

**前置**：本地已安装 Maven、Node.js，可 SSH 登录服务器。

```bash
# 设置数据库密码（必填）
export MUSHENG_DB_PASSWORD="你的数据库密码"

# 执行部署（替换为你的服务器 IP）
./scripts/deploy-local.sh 47.96.123.45

# 指定 SSH 用户（默认 root）
./scripts/deploy-local.sh 47.96.123.45 ubuntu

# 使用 SSH 密钥
SSH_KEY=~/.ssh/aliyun.pem ./scripts/deploy-local.sh 47.96.123.45
```

### 8.2 方式二：仅服务器端部署（文件已上传时）

当 jar、前端 dist、SQL 已上传到服务器时，在**服务器上**执行：

```bash
# 将部署包放在 /tmp/musheng-deploy，包含：
#   - musheng-web-1.0.0-SNAPSHOT.jar
#   - dist/（前端构建产物）
#   - musheng_tax.sql

# 上传脚本到服务器后执行
chmod +x deploy-server.sh
MUSHENG_DB_PASSWORD="你的数据库密码" ./deploy-server.sh /tmp/musheng-deploy
```

### 8.3 脚本说明

| 脚本 | 运行位置 | 作用 |
|------|----------|------|
| `scripts/deploy-local.sh` | 本地 | 构建前后端 → 打包 → 上传 → 远程执行 deploy-server.sh |
| `scripts/deploy-server.sh` | 服务器 | 安装 Java/MySQL/Nginx → 配置 → 部署应用 → 启动服务 |

### 8.4 仅重启应用（不重装环境）

```bash
sudo systemctl restart musheng
sudo systemctl reload nginx
```
