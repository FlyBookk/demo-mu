## 更新记录

### 2026-01-24 SKU字段映射修正

**问题**：ERP数据导入时，sku字段映射错误，应使用ERP报表中的 `MSKU` 字段而非 `SKU` 字段。

**修改内容**：
1. `ErpSettlementParser.java` - 聚合时使用 `MSKU` 作为 sku 值
2. `v1.7_field_mapping_template_update.sql` - ERP模板中 `SKU` → `MSKU`
3. `销售数据-字段优化分析.md` - 更新ERP字段映射说明

### 2026-01-24 去重逻辑移除时间字段

**问题**：原始数据和ERP数据的 `transaction_date` 时间不一致，无法作为去重约束条件。

**修改内容**：
- 唯一键由 `settlement_id + order_id + transaction_type + sku + transaction_date` 
- 调整为 `settlement_id + order_id + transaction_type + sku`
- 更新相关代码、SQL索引和文档
