## 二、功能测试

### 测试1：批量导入 - 文件上传
1. 访问 `http://localhost:5173/advertising/import`
2. 选择"文件上传"标签页
3. 上传Excel文件（包含账单周期、发票编号等字段）
4. 点击"下一步"查看数据预览
5. 点击"开始导入"
6. 验证导入结果统计（成功数、去重数、失败数）

### 测试2：批量导入 - 手动录入
1. 访问导入页面
2. 选择"手动录入"标签页
3. 点击"添加一行数据"
4. 填写店铺名称、发票编号、账单周期、费用、币种
5. 提交导入
6. 验证导入成功

### 测试3：去重测试
1. 导入包含重复发票编号的数据
2. 验证去重统计准确
3. 查看去重的发票编号列表

### 测试4：列表查询
1. 访问 `http://localhost:5173/advertising/list`
2. 测试账单周期范围搜索
3. 测试发票编号搜索
4. 测试站点筛选
5. 验证账单周期显示格式: `YYYY-MM-DD ~ YYYY-MM-DD`

### 测试5：数据校验
1. 导入开始日期 > 结束日期的数据（应失败）
2. 导入不支持的币种（应失败）
3. 导入缺少必填字段的数据（应失败）
