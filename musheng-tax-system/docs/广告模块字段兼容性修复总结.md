### 2. AdvertisingDataServiceImpl.java ✅

**位置**: `musheng-business/src/main/java/com/musheng/business/advertising/service/impl/AdvertisingDataServiceImpl.java`

**修复内容**:

#### copyProperties方法（第231-270行）

**问题**: 旧的简化版API（POST/PUT /v1/advertising）使用 `AdvertisingDataRequest` DTO，包含旧字段名。需要兼容映射到新Entity。

**修复前**:
```java
private void copyProperties(AdvertisingDataRequest request, AdvertisingData entity) {
    entity.setSiteCode(request.getSiteCode());
    entity.setAttachmentPath(request.getAttachmentPath());
    entity.setRemark(request.getRemark());
    // 缺少关键字段映射！
}
```

**修复后**:
```java
private void copyProperties(AdvertisingDataRequest request, AdvertisingData entity) {
    entity.setSiteCode(request.getSiteCode());
    entity.setAttachmentPath(request.getAttachmentPath());
    entity.setRemark(request.getRemark());

    // yearMonth (YYYY-MM) -> billingStartDate + billingEndDate
    if (request.getYearMonth() != null) {
        LocalDate startDate = LocalDate.parse(request.getYearMonth() + "-01");
        LocalDate endDate = startDate.withDayOfMonth(startDate.lengthOfMonth());
        entity.setBillingStartDate(startDate);
        entity.setBillingEndDate(endDate);
    }

    // invoiceNo -> invoiceNumber
    if (request.getInvoiceNo() != null) {
        entity.setInvoiceNumber(request.getInvoiceNo());
    }

    // amount -> cost (同时设置invoiceAmount)
    if (request.getAmount() != null) {
        entity.setCost(request.getAmount());
        entity.setInvoiceAmount(request.getAmount());
    }

    // currencyCode -> currency
    if (request.getCurrencyCode() != null) {
        entity.setCurrency(request.getCurrencyCode());
    }

    // 设置默认值
    if (entity.getInvoiceStatus() == null) {
        entity.setInvoiceStatus("PAID_IN_FULL");
    }
    if (entity.getIssueDate() == null) {
        entity.setIssueDate(LocalDate.now());
    }
}
```

## 三、API兼容性说明

### 保留的旧API（向后兼容）

这些API继续使用旧的简化版字段名，通过 `copyProperties` 方法映射到新字段：

1. **创建广告数据**: `POST /v1/advertising`
   - 使用 `AdvertisingDataRequest` (旧字段名)
   - 自动转换: `yearMonth` → 月初到月末的账单周期

2. **更新广告数据**: `PUT /v1/advertising/{id}`
   - 使用 `AdvertisingDataRequest` (旧字段名)
   - 同样进行字段映射

3. **列表查询**: `GET /v1/advertising`
   - 接受 `yearMonth` 参数，但实际未使用（按创建时间排序）
   - 建议使用新的搜索接口

### 新的批量导入API（使用新字段）

4. **批量导入**: `POST /v1/advertising/import`
   - 使用 `AdvertisingDataImportRequest` (新字段名)
   - 支持完整的18个字段
   - 支持双日期的账单周期

5. **条件搜索**: `GET /v1/advertising/search`
   - 使用新字段 `billingStartDate`, `billingEndDate`, `invoiceNumber`
   - 更精确的查询能力
