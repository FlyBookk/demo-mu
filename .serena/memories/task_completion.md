# 任务完成检查清单

## 代码修改后

### 前端
1. 检查 TypeScript 类型错误
2. 运行 `npm run lint` 检查 ESLint
3. 确保页面功能正常

### 后端
1. 检查编译错误
2. 运行相关单元测试
3. 确保 API 响应正确
