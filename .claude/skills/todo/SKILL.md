# 待办项管理 Skill

此 skill 用于智能查看和管理项目各阶段的待办事项。

## 使用方法

```bash
/todo [阶段名称]
/todo [阶段名称] update [任务编号] [状态]
```

## 参数说明

- `阶段名称`：all | 需求 | 设计 | 开发 | 测试 | 验收
- `update`：更新任务状态（可选）
- `任务编号`：如 1.1, 2.3 等
- `状态`：待处理 | 进行中 | 已完成

## 功能说明

### 1. 查看待办项（默认行为）

当用户调用 `/todo [阶段]` 时：

1. **读取对应的待办项文档**
2. **解析并展示关键信息**：
   - 阶段状态（✅ 已完成 | ⏳ 进行中 | 🔲 未开始）
   - 负责的 Agent
   - 待办事项清单及完成状态
   - 进度统计
   - 阶段交付物
   - 关键问题汇总

3. **智能分析**：
   - 计算完成百分比
   - 识别阻塞项（P0 问题）
   - 高亮延期任务
   - 显示下一步计划

### 2. 更新待办项（update 模式）

当用户调用 `/todo [阶段] update [任务编号] [状态]` 时：

1. 读取对应文档
2. 找到指定任务
3. 更新任务状态标记（✅ | ⏳ | 🔲）
4. 更新完成日期（如果状态改为已完成）
5. 保存文档
6. 显示更新结果

### 3. 项目总览（all）

当用户调用 `/todo all` 时：

1. 读取项目总待办项文档
2. 显示：
   - 五个阶段的总体进度
   - 当前阶段
   - 下一阶段准入条件
   - 全局阻塞问题
   - 关键里程碑

## 智能提示

在显示待办项时，还应该提供：

1. **角色相关性提醒**
   - 如果当前处于某个 agent 角色模式，高亮该角色相关的任务

2. **依赖关系提醒**
   - 如果某个任务依赖其他任务，显示依赖关系

3. **风险预警**
   - 如果有任务延期或阻塞，给出风险提示

4. **操作建议**
   - 根据当前状态，建议下一步应该做什么

## 示例

**示例1：查看设计阶段待办**
```
用户: /todo 设计

输出:
## 设计阶段待办项概览
**状态**: ✅ 有条件通过
**负责Agent**: 交互设计 + 前端研发 + 后端研发
**更新时间**: 2026-01-19

### 📊 进度统计
- 总任务数: 38
- 已完成: 33 (87%)
- 待处理: 5 (13%)

### ⏳ 待处理任务
- 2.6 修改交互设计（P0问题待解决）
- 2.7 确认评审通过
- 5.4 确认接口协议
- 5.6 修改技术设计
- 5.7 确认评审通过

### 🚨 阻塞问题
- P0: 业务状态码判断不一致（9个）
- P1: 重要问题（10个）

### 💡 下一步建议
1. 优先解决 P0 问题
2. 前后端对齐接口协议
3. 完成后可进入开发阶段
```
