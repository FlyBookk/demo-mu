# 文档快速查询 Skill

此 skill 用于快速查找和查看项目中的各类文档。

## 使用方法

```bash
/doc [类型] [关键词]
/doc search [关键词]
/doc list [类型]
```

## 参数说明

- `类型`：需求 | 设计 | 测试 | 评审 | 管理 | 部署 | 业务
- `关键词`：搜索关键词（可选）
- `search`：全文档搜索
- `list`：列出某类型的所有文档

## 文档类型映射

| 类型 | 目录路径 | 包含文档 |
|------|---------|---------|
| 需求 | `项目文档/01_需求文档/` | PRD、需求评审记录 |
| 设计 | `项目文档/02_设计文档/` | 交互设计、前端技术设计、后端技术设计 |
| 测试 | `项目文档/03_测试文档/` | 测试用例、测试报告、测试验收 |
| 评审 | `项目文档/04_评审记录/` | 各类评审记录、联调报告、自测报告 |
| 管理 | `项目文档/05_项目管理/` | 各阶段待办项、项目总待办 |
| 部署 | `项目文档/06_部署文档/` | 部署指南、环境配置 |
| 业务 | 根目录 | 项目白皮书、数据处理说明、汇率数据 |
| 流程 | `.agent/workflows/` | 工作流程规范、开发诉求 |
| 角色 | `.claude/agents/` | 各角色agent定义 |

## 功能说明

### 1. 按类型查询（默认行为）

当用户调用 `/doc [类型]` 或 `/doc [类型] [关键词]` 时：

#### 步骤1：定位文档目录
根据类型，定位到对应的文档目录

#### 步骤2：列出或搜索文档
- 如果没有提供关键词：列出该类型的所有文档
- 如果提供了关键词：在该类型文档中搜索关键词

#### 步骤3：展示文档清单
```markdown
## 📂 [类型] 文档

找到 X 个文档：

### 主要文档
1. **[文档名称]** - [路径]
   - 最后更新: YYYY-MM-DD
   - 大小: XX KB
   - 简介: [文档简介或目录]
   - 状态: ✅ 最新 / ⚠️ 待更新 / 🔲 未完成

2. **[文档名称]** - [路径]
   ...

---

💡 使用 `/doc [类型] [关键词]` 搜索特定内容
💡 使用 Read 工具查看完整文档内容
```

### 2. 全文搜索（search 模式）

当用户调用 `/doc search [关键词]` 时：

#### 步骤1：全局搜索
在所有项目文档中搜索关键词（使用 Grep 工具）

#### 步骤2：按相关性排序
根据匹配次数和文档类型排序结果

#### 步骤3：展示搜索结果
```markdown
## 🔍 搜索结果: "[关键词]"

找到 X 个匹配项：

### 🎯 高度相关（匹配5次以上）
1. **[文档名称]** - [类型]
   - 路径: [路径]
   - 匹配: X处
   - 摘要: [...关键词...] [...关键词...]

### 📌 相关（匹配2-4次）
1. **[文档名称]** - [类型]
   ...

### 💡 可能相关（匹配1次）
1. **[文档名称]** - [类型]
   ...

---

💡 使用 Read 工具查看完整内容
💡 使用 Grep 工具查看匹配上下文
```

### 3. 列出文档（list 模式）

当用户调用 `/doc list [类型]` 时：

以树形结构展示该类型的所有文档：

```markdown
## 📁 [类型] 文档列表

```
项目文档/02_设计文档/
├── 交互设计/
│   ├── 交互设计文档.md ✅
│   └── 原型图/
│       ├── 登录页面.png
│       └── Dashboard.png
├── 前端技术设计/
│   └── 前端技术设计文档.md ✅
└── 后端技术设计/
    └── 后端技术设计文档.md ✅
```

共计: X 个文件夹，Y 个文档

---

💡 使用 `/doc 设计 [关键词]` 搜索特定内容
```

### 4. 快速摘要

使用 AI 生成文档摘要：

```markdown
### 📋 文档摘要

**文档类型**: 需求文档
**文档名称**: 亚马逊转口贸易报税系统需求文档

**核心内容**:
- 业务背景: 亚马逊转口贸易业务需要向税局申报
- 用户角色: 财务人员、管理员
- 核心功能:
  1. 基础配置管理
  2. 数据导入（销售/配送/广告数据）
  3. 字段映射画布
  4. 汇率管理
  5. 汇总报表生成
  6. 系统管理

**关键亮点**:
- 动态字段映射支持多站点
- 汇率自动匹配节假日顺延
- 退款按配送日期归属月份

**非功能需求**:
- 支持大文件导入（10万+行）
- 响应时间 < 3秒
- 支持Chrome、Edge浏览器
```
