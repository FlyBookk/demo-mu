# 流程自动化系统使用指南

本指南介绍如何使用项目中的自动化流程系统，提升开发效率。

---

## 📁 目录结构

```
.claude/
├── skills/                    # 自定义Skills
│   ├── dev-flow/             # 功能开发流程
│   │   └── SKILL.md
│   ├── bugfix-flow/          # Bug修复流程
│   │   └── SKILL.md
│   ├── agent/                # 角色切换（内置）

│
├── workflows/                # 工作流程文档
│   ├── component-development.md   # 组件开发流程

```

## 🎯 快速开始

### 方式一：使用自动化Skill（推荐）

自动化skill会引导你完成整个流程。

#### 1. 开发新功能
```
/dev-flow 字段映射画布组件
```

执行流程：
1. 自动切换到前端角色
2. 搜索相关文档
3. 分析技术方案
4. 生成开发计划
5. 执行代码开发
6. 自测验证
7. 更新待办状态

#### 2. 修复Bug
```
/bugfix 表格数据不刷新
```

执行流程：
1. 收集Bug信息
2. 搜索相关代码
3. 问题定位
4. 根因分析
5. 设计修复方案
6. 执行修复
7. 自测验证
8. 生成修复报告

### 方式二：使用流程文档（手动）

适合需要自己掌控每一步的场景。

```
请按照 .claude/workflows/component-development.md 执行组件开发流程
```

我会读取流程文档，按照文档中的步骤引导你完成开发。

### 方式三：使用代码模板（快速）

直接复制模板代码，手动修改。

```
请使用 .claude/templates/component.vue 模板创建一个数据表格组件
```

## 📖 详细说明

### 1. 自定义Skills

#### /dev-flow - 功能开发流程

**用途**: 开发新的前端功能或组件

**语法**:
```
/dev-flow [功能名称]
```

**示例**:
```
/dev-flow 数据表格组件
/dev-flow 销售数据查询接口
/dev-flow 字段映射画布
```

**流程步骤**:
1. 切换到前端角色
2. 确认开发任务
3. 搜索相关文档（PRD、设计文档、技术设计）
4. 分析技术方案（组件位置、技术选型、接口依赖）
5. 生成开发计划（文件列表、技术要点、开发步骤）
6. 执行开发（创建文件、编写代码、编写样式）
7. 自测验证（功能测试、代码检查）
8. 更新待办状态

**适用场景**:
- 开发新的Vue组件
- 封装新的API接口
- 实现新的业务功能
- 创建工具函数

---

#### /bugfix - Bug修复流程

**用途**: 修复已发现的Bug

**语法**:
```
/bugfix [Bug描述或ID]
```

**示例**:
```
/bugfix 登录失败提示401错误
/bugfix 表格数据不刷新
/bugfix #123
```

**流程步骤**:
1. 收集Bug信息（描述、重现步骤、环境）
2. 搜索相关代码
3. 问题定位（分析可能原因）
4. 根因分析（找到问题根源）
5. 设计修复方案（列出多个方案，推荐最优）
6. 执行修复（修改代码、更新类型）
7. 自测验证（功能验证、回归测试）
8. 生成修复报告
9. 提交评审

**适用场景**:
- 功能缺陷修复
- 性能问题优化
- 用户体验问题
- 兼容性问题

## 🔧 自定义扩展

### 添加新的Skill

1. 在 `.claude/skills/` 下创建新目录
2. 创建 `SKILL.md` 文件
3. 按照现有skill的格式编写
4. 重启Claude Code生效

### 添加新的流程文档

1. 在 `.claude/workflows/` 下创建新的Markdown文件
2. 编写流程步骤
3. 在文档中使用 `/skill-name` 调用其他skills

### 添加新的代码模板

1. 在 `.claude/templates/` 下创建新的模板文件
2. 使用占位符标记需要替换的部分（如 `[ModuleName]`）
3. 在使用时引用模板路径

## ❓ 常见问题

### Q1: Skill调用失败怎么办？
检查：
1. Skill文件是否存在于 `.claude/skills/` 目录
2. 文件名是否为 `SKILL.md`
3. 格式是否正确
4. 是否需要重启Claude Code

### Q2: 如何修改现有的流程？
直接编辑 `.claude/workflows/` 下的Markdown文件即可，无需重启。

### Q3: 可以创建自己的Skill吗？
可以！按照现有skill的格式创建新的SKILL.md文件即可。

### Q4: 流程文档和Skill有什么区别？
- **Skill**: 自动化执行的脚本，会主动引导完成任务
- **流程文档**: 参考指南，需要手动逐步执行

### Q5: 模板中的占位符如何替换？
告诉我使用模板创建新文件时，我会自动替换占位符。
