## 5. 工作规范

### 5.1 文档规范

```markdown
# 需求文档结构规范

## 1. 文档版本信息
- 版本号、日期、修订记录

## 2. 项目背景
- 业务背景、项目目标、范围边界

## 3. 功能需求
- 按模块组织，包含功能描述、业务规则、数据定义

## 4. 非功能需求
- 性能、安全、兼容性等

## 5. 附录
- 术语表、数据字典、确认记录
```

### 5.2 沟通规范

- 需求变更必须形成书面记录
- 重要决策需要相关方确认
- 保持需求文档与实际开发同步更新

### 5.3 质量标准

| 标准项 | 要求 |
|--------|------|
| 完整性 | 需求无遗漏，覆盖所有业务场景 |
| 一致性 | 术语统一，无矛盾描述 |
| 可验证 | 每条需求可测试、可验收 |
| 可追溯 | 需求有来源，变更有记录 |

## 7. 项目特定知识

### 7.1 核心业务概念

| 概念 | 说明 |
|------|------|
| 转口贸易 | 货物从A国采购，经B国中转，销售到C国，不入境中国 |
| 站点 | 亚马逊销售区域：US/CA/UK/DE |
| 配送数据 | 亚马逊FBA配送记录，包含收入计算所需字段 |
| 交易明细 | 亚马逊结算报告，包含订单/退款/费用明细 |
| 汇率中间价 | 中国人民银行公布的外汇汇率 |

### 7.2 核心计算规则

```
收入总额 = 商品价格 + 商品税 + 运费 + 运费税 + 礼品包装 + 促销折扣
退款金额 = 同上（以配送日期为准归属月份）
净收入额 = 收入总额 - 退款金额
成本 = 亚马逊服务费 + 广告费 + 采购金额
采购金额 = 净收入额 × 96% - 亚马逊服务费 - 广告费
```

### 7.3 数据处理要点

- 不同站点表头语言/格式不同，需要映射配置
- 汇率按交易当日计算，节假日顺延
- 退款以配送日期归属月份，非退款发生日期
- Refund_Retrocharge 不在计算范畴

## 8. 常用提示词模板

### 8.1 需求分析

```
请分析以下业务需求：
[需求描述]

输出：
1. 需求理解（用自己的话复述）
2. 功能拆解（分解为具体功能点）
3. 业务规则（涉及的计算/校验逻辑）
4. 待确认问题（需要与业务确认的点）
5. 优先级建议
```

### 8.2 文档审查

```
请审查以下需求文档，检查：
1. 完整性：是否有遗漏的功能/场景
2. 一致性：是否有矛盾的描述
3. 可验证性：每条需求是否可测试
4. 清晰度：是否有模糊不清的表述

[文档内容]
```

### 8.3 变更评估

```
请评估以下需求变更的影响：
[变更内容]

输出：
1. 影响范围（哪些模块/功能受影响）
2. 工作量估算
3. 风险评估
4. 建议处理方式
```
