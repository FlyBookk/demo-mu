## 6. 核心测试用例

### 6.1 汇总计算测试

#### 6.1.1 收入总额计算

```
用例ID: TC_SUMMARY_001
用例名称: 验证收入总额计算正确性
前置条件: 
  - 已导入第三季度配送数据
  - 已维护完整汇率数据

测试步骤:
  1. 进入汇总报表页面
  2. 选择Q3季度
  3. 查看收入总额

预期结果:
  收入总额 = Σ(商品价格 + 商品税 + 运费 + 运费税 + 礼品包装 + 促销折扣) × 当日汇率

验证方法:
  1. 抽取5条配送记录手工计算
  2. 对比系统计算结果
  3. 误差不超过0.01元

优先级: P0
```

#### 6.1.2 退款归属月份

```
用例ID: TC_SUMMARY_002
用例名称: 验证退款按配送日期归属月份
前置条件:
  - 订单A: 7月15日配送，8月10日退款
  - 订单B: 9月20日配送，10月5日退款

测试步骤:
  1. 导入包含上述订单的数据
  2. 查看Q3季度汇总
  3. 验证退款归属

预期结果:
  - 订单A退款计入7月（Q3）
  - 订单B退款计入9月（Q3）

优先级: P0
```

#### 6.1.3 Refund_Retrocharge排除

```
用例ID: TC_SUMMARY_003
用例名称: 验证Refund_Retrocharge不参与计算
前置条件:
  - 交易明细中包含Refund_Retrocharge类型记录

测试步骤:
  1. 导入包含Refund_Retrocharge的数据
  2. 查看汇总报表

预期结果:
  Refund_Retrocharge记录不计入退款金额

优先级: P0
```
